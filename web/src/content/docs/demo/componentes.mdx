## Bajo el capó

<BajoElCapo titulo="la división entera">
`7 / 2` entre `i32` se compila a una única instrucción de división entera del procesador, que deja el cociente (3) en un registro y el resto (1) en otro.
</BajoElCapo>

## Trampa típica

<Trampa titulo="esperar decimales de dos enteros">
❌ Mal:

```rust
let media = 7 / 2; // vale 3, y es i32
```

✅ Bien:

```rust
let media = 7.0 / 2.0; // vale 3.5, y es f64
```
</Trampa>

<Historia titulo="por qué Rust comprueba el desbordamiento solo en debug">
Comprobar cada suma cuesta un poco de velocidad. Rust decidió comprobarlo siempre mientras desarrollas (debug) y, en release, dejar que el valor dé la vuelta salvo que pidas otra cosa con `checked_add`, `wrapping_add` o `saturating_add`.
</Historia>

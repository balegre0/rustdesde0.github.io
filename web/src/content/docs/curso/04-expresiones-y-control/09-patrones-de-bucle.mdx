Casi todos los problemas con bucles son variaciones de **cuatro recetas**. Si las reconoces, la mitad del trabajo está hecha.

## La idea

| Receta | Variables | Dentro del bucle |
|---|---|---|
| **Contar** | `let mut cuenta = 0;` | `if condición { cuenta += 1; }` |
| **Acumular** | `let mut total = 0;` (o `1` para multiplicar, o `String::new()`) | `total += x;` |
| **El mejor hasta ahora** | `let mut mejor = primero;` | `if x > mejor { mejor = x; }` |
| **Buscar y parar** | ninguna | `if encontrado { break …; }` |

## Bajo el capó

<BajoElCapo>

**En el mundo 14 escribirás esto en una línea.** Los iteradores tienen cada receta ya hecha: `filter(…).count()` cuenta, `sum()` acumula, `max()` y `enumerate().max_by_key(…)` buscan el mejor y `position(…)` busca y para. Y el compilador genera **el mismo código máquina** que con el bucle escrito a mano. Conviene saber hacerlo con bucles primero: así sabes qué hace cada método por dentro.

**`% 10` y `/ 10` en binario.** El procesador no tiene una instrucción para dividir entre 10 rápido, pero el compilador sabe convertir la división entre una constante en una multiplicación y un desplazamiento, mucho más baratos.

</BajoElCapo>

## Trampa típica

<Trampa titulo="Empezar el máximo en 0">

❌ `let mut maxima = 0;` para buscar la temperatura más alta de un invierno con `[-5, -2, -8]`. El resultado sería `0`, una temperatura que no está en la lista.

✅ Empieza con el **primer elemento** (`lista[0]`, comprobando antes que no esté vacía) o usa `i32::MIN`.

</Trampa>

## La idea

`if condición { A } else { B }` evalúa la condición. Si es `true`, ejecuta el bloque `A`; si es `false`, el bloque `B`. Como cada bloque es una expresión (lo viste en la lección anterior), **el `if` entero también es una expresión**: vale lo que valga el bloque elegido. Por eso puedes escribir `let ropa = if calor { "camiseta" } else { "jersey" };`.

Para que eso funcione, Rust pone dos condiciones. Primera: **las dos ramas deben producir el mismo tipo**. La variable `ropa` tiene un único tipo, fijado al compilar, así que no puede ser «a veces número, a veces texto». Segunda: si usas el valor, **tiene que haber `else`**. Sin `else`, cuando la condición es falsa no hay ninguna rama que dé un valor, y el `if` vale `()`.

La condición, además, tiene que ser un **`bool`** de verdad. Rust no convierte números en verdadero/falso por su cuenta: si quieres preguntar «¿hay mensajes?», escribe `mensajes > 0`.

## Pruébalo

<Ejecutar ej="m04/if-expresion" />

1. El primer `if` se usa como decisión: cada rama imprime algo y vale `()`.
2. El segundo produce un `&str` que se guarda en `ropa`.
3. La cadena `else if` comprueba las condiciones **de arriba abajo** y se queda con la primera verdadera. Con 34 grados, `>= 40` es falso y `>= 30` es verdadero, así que `nivel` vale 2: la última rama ni se mira.

## Bajo el capó

<BajoElCapo>

**El `if` se convierte en un salto.** El compilador traduce `if` a una comparación seguida de un **salto condicional**: una instrucción de la CPU que dice «si el resultado fue falso, sigue leyendo en otra dirección». Las dos ramas existen en el programa; solo se ejecuta una.

**Un `if` sin `else` vale `()`.** Rust lo trata como si hubieras escrito `else { () }`. Por eso este caso sí compila cuando no usas el valor (el `if` de la línea 1 del ejemplo), y falla cuando sí lo usas.

**El tipo se decide antes de ejecutar.** El compilador calcula el tipo de cada rama. Si coinciden, ese es el tipo del `if`. Si no, el error E0308 te enseña las dos: la rama que fijó el tipo («expected because of this») y la que no encaja.

</BajoElCapo>

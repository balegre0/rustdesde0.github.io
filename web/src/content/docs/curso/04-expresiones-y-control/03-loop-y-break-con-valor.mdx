## La idea

`loop { ... }` repite su bloque **para siempre**. Parece peligroso, pero es la forma más honesta de decir «repite hasta que yo diga basta». Para decir basta usas **`break`**, normalmente dentro de un `if`. Y para saltarte el resto de una vuelta y pasar a la siguiente, **`continue`**.

Lo especial de Rust es que `loop` también es una expresión. Si escribes `break valor;`, el bucle termina y **todo el `loop` vale `valor`**. Así puedes escribir `let resultado = loop { ... break x; };` y guardar directamente lo que encontraste.

Este patrón aparece mucho: reintentar algo hasta que salga bien, buscar el primer número que cumple una condición, o leer datos hasta que se acaben.

## Pruébalo

<Ejecutar ej="m04/loop-break-valor" />

1. `potencia` empieza en 1 y se duplica en cada vuelta: 2, 4, 8... 512, 1024.
2. Cuando supera 1000 (en la vuelta 10), `break potencia;` sale del bucle y entrega 1024.
3. Ese 1024 queda guardado en `resultado`. No hizo falta una variable «encontrado» ni nada parecido.

## Bajo el capó

<BajoElCapo>

**Un `loop` es un salto hacia atrás.** El compilador pone una etiqueta al principio del cuerpo y, al final, una instrucción que vuelve a ella. `break` es un salto hacia **después** del bucle; `continue`, un salto hacia el **principio**.

**El tipo de un `loop`.** Si todos los `break` llevan valor del mismo tipo, ese es el tipo del `loop`. Si los `break` no llevan valor, el `loop` vale `()`. ¿Y si no hay ningún `break`? Entonces el bucle nunca termina, y su tipo es `!`, el tipo «nunca» (*never*): una expresión que jamás produce un valor porque jamás acaba. Lo verás de nuevo con `panic!`.

**Por qué el compilador se fía de `loop`.** El compilador sabe que solo se sale de un `loop` por un `break`. Por eso puede garantizar que, después del bucle, `resultado` tiene valor. Con `while` no puede (lo verás en la siguiente lección).

</BajoElCapo>

## Trampa típica

<Trampa titulo="Olvidar avanzar">

❌ Si nada dentro del `loop` cambia lo que compruebas, el `break` no llega nunca y el programa se queda colgado:

```rust
let mut n = 1;
let r = loop {
    if n > 1000 { break n; }
    // olvidé n *= 2;
};
```

✅ Antes de escribir el `break`, pregúntate: ¿qué cambia en cada vuelta para que algún día se cumpla la condición?

</Trampa>

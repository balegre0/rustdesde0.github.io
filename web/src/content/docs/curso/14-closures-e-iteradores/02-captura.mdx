Vas a saber, mirando el cuerpo de un closure, **cómo** se queda con cada variable: prestada, prestada en exclusiva o movida. Y vas a entender los errores que salen cuando lo olvidas.

## La idea

El compilador mira **qué hace el cuerpo** con cada variable capturada y elige la forma más suave que funcione:

| El cuerpo… | Captura | Igual que |
|---|---|---|
| solo lee la variable | préstamo compartido | `&x` |
| la modifica | préstamo exclusivo | `&mut x` |
| la consume (la mueve fuera, la destruye…) | por valor | mover `x` |

Mientras el closure existe, **ese préstamo existe**. Y entonces se aplican las reglas que ya conoces: muchos lectores **o** un solo escritor. Si un closure tiene `&mut contador`, no puedes leer `contador` por fuera hasta que el closure deje de usarse. Es la misma regla que evita el aliasing con mutación en el mundo 7, no una regla nueva.

La palabra **`move`** cambia la elección: captura **todo por valor**. Se usa cuando el closure tiene que vivir más que la función que lo crea (devolverlo, o mandarlo a otro hilo en el mundo 17). Ojo: con `move`, un tipo `Copy` se copia, pero una `String` o un `Vec` se mueven y ya no los puedes usar fuera.

## Bajo el capó

<BajoElCapo>

Para `let mut visitar = || visitas += 1;` el compilador genera, aproximadamente, esto (no es código que puedas escribir tal cual):

```rust
struct ClosureVisitar<'a> {
    visitas: &'a mut i32,     // captura por préstamo exclusivo
}
// …y una implementación de FnMut cuyo cuerpo hace: *self.visitas += 1
```

El struct guarda un **`&mut i32`** con un tiempo de vida `'a`: por eso, mientras exista `visitar`, `visitas` está prestada en exclusiva. Con `move`, el campo sería un `i32` (la copia) y no habría préstamo ninguno.

**Captura disjunta** (*disjoint capture*, edición 2021): el closure captura la **ruta exacta** que usa, por ejemplo `j.nombre`, no la variable entera `j`. Por eso esto compila:

<Ejecutar ej="m14/captura-disjunta" />

El closure tiene un préstamo compartido de `j.nombre` y nada más, así que `j.puntos += 10` no choca con él.

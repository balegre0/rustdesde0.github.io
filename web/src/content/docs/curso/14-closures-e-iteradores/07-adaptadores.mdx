## La idea

Un **adaptador** (*iterator adapter*) es un método que recibe un iterador y devuelve **otro iterador**. No calcula nada todavía (pereza); solo añade un paso a la receta. Los más usados:

| Adaptador | Qué hace | Ejemplo |
|---|---|---|
| `map(f)` | transforma cada elemento | `[3, 8]` → `[6, 16]` con `\|x\| x * 2` |
| `filter(p)` | deja pasar los que cumplen `p` | quedarse con los `> 3` |
| `enumerate()` | añade la posición: `(i, x)` | `(0, 3), (1, 8)…` |
| `zip(otro)` | empareja con otro iterador | `("Ana", 3), ("Leo", 8)…` |
| `take(n)` / `skip(n)` | los primeros `n` / sáltate `n` | |
| `chain(otro)` | uno detrás de otro | `1, 2` y luego `8, 9` |
| `flat_map(f)` | cada elemento da varios, y se aplanan | palabras → letras |
| `rev()` | al revés (si el iterador sabe ir hacia atrás) | |

Se leen de izquierda a derecha, como una frase: «de `v`, filtra los mayores que 3, multiplícalos por 2». Cada pieza es pequeña y fácil de comprobar por separado.

## Bajo el capó

<BajoElCapo>

Cada adaptador es un **struct genérico** que envuelve al anterior. `filter` devuelve un `Filter<I, P>` que guarda el iterador `I` y el closure `P`; su `next()` llama al `next()` de dentro hasta encontrar uno que cumpla `P`. Puedes ver el tipo real con un truco: pedirle al compilador que la cadena sea `()` y leer el error.

```text
error[E0308]: mismatched types
  = note: expected struct `Map<Filter<std::slice::Iter<'_, {integer}>, {closure@tipo-de-cadena.rs:4:30: 4:33}>, {closure@tipo-de-cadena.rs:4:47: 4:50}>`
          found unit type `()`
```

(Extracto del error real de `m14/tipo-de-cadena`.) Son **muñecas rusas**: `Map` contiene un `Filter` que contiene un `slice::Iter`, y cada closure va guardado dentro de su adaptador. No hay listas intermedias en memoria: cuando el consumidor pide un elemento, la petición baja por las muñecas y el elemento sube transformado.

Como todo son tipos concretos (genéricos, no `dyn`), el compilador conoce la cadena entera y puede fundirla en un solo bucle. Lo comprobarás con el ensamblador dentro de dos lecciones.

</BajoElCapo>

Hasta ahora, para recorrer una lista escribías un `for` y, dentro, hacías las cuentas a mano. En este mundo aprendes a decir **qué** quieres («los pares, al cuadrado, sumados») en vez de **cómo** hacerlo paso a paso. Dos piezas lo hacen posible:

- Un **closure** es una función pequeña, sin nombre, que puede **capturar** variables de alrededor. Se escribe con barras: `|x| x * 2`.
- Un **iterador** es algo que entrega valores **de uno en uno** cuando se los pides. Se encadenan como piezas de una tubería: `v.iter().filter(...).map(...).sum()`.

Y una promesa que vas a comprobar con el ensamblador delante: esas cadenas no cuestan nada extra. El compilador las convierte en el mismo código máquina que el bucle que habrías escrito tú.

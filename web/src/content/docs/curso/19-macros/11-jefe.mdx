El jefe de este mundo es una macro de las que se escriben en proyectos reales: a partir de una lista de nombres genera un `enum`, su número de variantes, un array con todas ellas y un método que devuelve el nombre de cada una. Usa casi todo lo que has aprendido.

## La idea

Repasemos qué pieza de la macro usa cada lección:

| Pieza | Para qué | Lección |
|---|---|---|
| `$(#[$meta:meta])*` | reenviar atributos como `#[derive(...)]` | 3 y 4 |
| `$vis:vis` | respetar `pub`, `pub(crate)` o nada | 3 |
| `$($var:ident),+ $(,)?` | la lista de variantes, con coma final opcional | 4 |
| `contar!($($var)*)` | el número de variantes, como constante | 6 |
| `stringify!($var)` | el nombre como texto | 1 y 8 |
| `$nombre::$var` | rutas construidas con identificadores capturados | 3 |

El `match` de `nombre()` se genera con una repetición: un brazo por variante. Si mañana añades `Intermitente` a la lista, el enum, `N`, `TODOS` y `nombre()` se actualizan solos. Esa es la razón de ser de esta macro: mantener **sincronizadas** varias piezas de código que dependen de la misma lista.

## Bajo el capó

<BajoElCapo>
**¿Hace falta `Copy`?** Para este `main`, no: lo hemos comprobado quitando `Clone, Copy` y sigue compilando e imprimiendo lo mismo. Cada vez que escribes `Semaforo::TODOS` se crea un array nuevo (una constante se copia en cada uso), así que el `for` puede moverlo, y `==` compara por referencia. Pero en cuanto guardas el array en una variable y sacas un elemento con `let b = a[0];`, el compilador protesta con `error[E0508]: cannot move out of type [Semaforo; 3], a non-copy array`: sacar un valor de un array lo dejaría con un hueco. Un enum sin datos es tan barato de copiar como un número, así que pedir `Clone, Copy` es lo natural.

**Qué se genera.** Para tres variantes, la macro produce un `enum` de tres variantes sin datos (que ocupa 1 byte), una constante `N = 1 + 1 + 1 + 0`, un array de 3 elementos y un `match` de tres brazos. Ni una línea se ejecuta para «calcular» nada de esto: todo existe antes de que arranque el programa.

**Límite de diseño.** Esta macro no permite variantes con datos (`Rojo(u8)`). Añadirlo complicaría mucho el patrón. Cuando una macro empieza a necesitar muchos casos especiales, es el momento de preguntarse si una derive procedural (lección 9) sería más clara.
</BajoElCapo>

## Trampa típica

<Trampa titulo="Reenviar atributos sin repetición">
❌ `(#[$meta:meta] enum ...)`: obliga a poner **exactamente un** atributo. Sin atributo, la macro no encaja; con dos, tampoco.

✅ `($(#[$meta:meta])* ...)` en el patrón y `$(#[$meta])*` en la plantilla: cero o más atributos, reenviados tal cual.
</Trampa>

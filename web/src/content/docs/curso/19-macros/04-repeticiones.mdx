## La idea

Una **repetición** (*repetition*) se escribe `$( … ) sep op`:

- Lo que va entre `$(` y `)` es el trozo que se repite.
- `sep` (opcional) es el **separador** entre repeticiones: casi siempre `,` o `;`.
- `op` dice cuántas veces: `*` (cero o más), `+` (una o más) o `?` (cero o una; no admite separador).

En la plantilla escribes otra repetición con las mismas metavariables, y el compilador la **desenrolla** una vez por cada elemento capturado. Por eso `$(+ $x)*` con `1, 2, 3` produce `+ 1 + 2 + 3`.

## Pruébalo

<Ejecutar ej="m19/mi-lista" titulo="Tu propio vec!" />

1. Dos reglas: la lista vacía y la que tiene al menos un elemento (`+`).
2. La plantilla usa **llaves dobles** `{{ … }}`: las de fuera delimitan la plantilla y las de dentro son un bloque de verdad. Así la macro puede declarar `let mut v` y devolver `v` como valor del bloque.
3. `$( v.push($x); )+` genera un `push` por elemento.

Cada repetición puede capturar varias metavariables a la vez:

<Ejecutar ej="m19/mapa" titulo="Un literal de mapa" />

`$($k:expr => $v:expr),*` captura parejas. El `=>` dentro del patrón es un token literal más (puede ir detrás de `expr`, lo permite el follow-set).

## Bajo el capó

<BajoElCapo>
La expansión real de `suma-rep.rs` (Rust 1.99.1):

```rust
{ ::std::io::_print(format_args!("{0}\n", 0)); };
{ ::std::io::_print(format_args!("{0}\n", 0 + 5)); };
{ ::std::io::_print(format_args!("{0}\n", 0 + 1 + 2 + 3)); };
{ ::std::io::_print(format_args!("{0}\n", 0 + 10 + 20 + 30)); };
```

No hay bucle: la «suma de una lista» se ha convertido en una expresión fija para cada llamada. El bucle lo ejecutó el compilador mientras expandía.

**Profundidad de repetición.** Cada metavariable tiene una profundidad: cuántas repeticiones la rodean en el patrón. En la plantilla debe aparecer dentro del mismo número de repeticiones. Si dos metavariables se desenrollan en la misma repetición de la plantilla, deben haberse capturado **el mismo número de veces**; si no, el compilador no sabe cuántas vueltas dar.
</BajoElCapo>

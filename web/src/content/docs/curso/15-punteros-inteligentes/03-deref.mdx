## La idea

El operador `*` sobre una referencia `&T` da el `T` al que apunta. Para que funcione con **tus** tipos, implementas el trait `Deref` (*desreferenciar*), que tiene un tipo asociado `Target` (qué hay dentro) y un método `deref(&self) -> &Target`. A partir de ahí, cuando escribes `*c`, el compilador lo reescribe como `*(c.deref())`. Así funcionan `Box`, `String` (cuyo `Target` es `str`), `Vec<T>` (`Target = [T]`), `Rc` y todos los punteros inteligentes de este mundo.

`Deref` hace una segunda cosa, todavía más útil: la **coerción de desreferencia** (*deref coercion*). Si una función pide `&str` y le pasas `&String`, el compilador ve que `String: Deref<Target = str>` y convierte sola la referencia. Y lo hace en **cadena**: `&Box<String>` → `&String` → `&str`. También ocurre al llamar a métodos: `s.len()` sobre una `MiCaja<String>` encuentra el `len` de `String` a través de `deref`.

Para **modificar** a través de `*` hace falta un segundo trait, `DerefMut`. Lo verás en la lección 5: `Rc` implementa `Deref` pero no `DerefMut`, y por eso no puedes cambiar lo que comparte.

## Bajo el capó

<BajoElCapo>

La coerción no es magia en ejecución: ocurre **al compilar**. El compilador ve que el tipo no encaja e inserta las llamadas a `deref`. La llamada `saluda(&b)` con `b: Box<String>` se convierte en algo equivalente a:

```rust
saluda(&**b);          // *b: String,  **b: str,  &**b: &str
// o, con los métodos a la vista:
saluda(Deref::deref(Deref::deref(&b)));
```

Cada `deref` de `Box` y `String` es trivial (devolver un puntero que ya tienen), así que con optimización desaparecen por completo: la coerción **no cuesta nada** en ejecución.

Reglas exactas (Reference, *Type coercions*): de `&T` a `&U` si `T: Deref<Target = U>`; de `&mut T` a `&mut U` si `T: DerefMut<Target = U>`; y de `&mut T` a `&U` si `T: Deref<Target = U>`. Nunca de `&T` a `&mut U`: eso rompería la regla de que un préstamo compartido no permite mutar (aliasing con mutación).

</BajoElCapo>

## Trampa típica

<Trampa titulo="Usar Deref para «heredar» métodos">

❌ Implementar `Deref` en un struct cualquiera solo para no escribir `self.campo.metodo()`:

```rust
struct Usuario { nombre: String, edad: u32 }
impl Deref for Usuario {
    type Target = String;
    fn deref(&self) -> &String { &self.nombre }
}
// usuario.len() ahora compila... ¿y qué significa la «longitud» de un usuario?
```

✅ `Deref` es para tipos que **son** un puntero o un envoltorio fino de otro valor (`Box`, `String`, un *newtype* `Nombre(String)`). Para lo demás, escribe métodos propios que deleguen: `fn nombre(&self) -> &str { &self.nombre }`.

</Trampa>

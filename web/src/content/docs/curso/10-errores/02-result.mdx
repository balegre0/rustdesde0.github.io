## La idea

`Result` es un enum de la biblioteca estándar, igual que `Option`:

```rust
enum Result<T, E> {
    Ok(T),    // salió bien: aquí está el valor
    Err(E),   // salió mal: aquí está el error
}
```

Una función que puede fallar **lo dice en su firma**: `fn dividir(a: i32, b: i32) -> Result<i32, String>`. Quien la llama recibe un `Result`, no un número, y no puede usarlo como número hasta tratar el caso `Err`. El error es un valor más: tiene tipo, se puede imprimir, guardar, pasar a otra función o convertir.

La diferencia con `Option` es la información. `None` solo dice «no hay»; `Err(e)` dice «no hay, **y este es el motivo**». Usa `Option` cuando la ausencia es normal y no necesita explicación (buscar algo que puede no estar) y `Result` cuando algo **falló** y quien llama querrá saber por qué.

## Pruébalo

<Ejecutar ej="m10/result" />

El paso 4 muestra que un error tiene dos formas de imprimirse: `{:?}` (Debug, para programadores: `ParseIntError { kind: PosOverflow }`) y `{}` (Display, para personas: `number too large to fit in target type`). Las verás a fondo en la lección 6.

## Bajo el capó

<BajoElCapo>

`Result` está marcado con el atributo **`#[must_use]`**: si llamas a una función que lo devuelve y tiras el valor, el compilador avisa. Es la diferencia entre «comprobé el error y decidí ignorarlo» (`let _ = guardar(…)`) y «se me olvidó».

En memoria, `Result<T, E>` es un enum normal: etiqueta + espacio para la variante más grande, con las mismas optimizaciones de nicho del mundo 9. Por ejemplo, `Result<u32, String>` ocupa 12 bytes en wasm32 (igual que un `String`): el puntero de `String` nunca es nulo y su capacidad no puede pasar de `isize::MAX`, así que sobran valores para codificar `Ok`. Devolver un `Result` **no cuesta más** que devolver un valor de ese tamaño: no hay ningún mecanismo oculto ni salto especial.

</BajoElCapo>

<Ejecutar ej="m10/result-ignorado" titulo="Aviso: unused Result that must be used" />

El programa dice «guardado» aunque `guardar("")` falló. El aviso de rustc te lo estaba diciendo. Nunca silencies este aviso sin pensar: si de verdad quieres ignorar el error, escribe `let _ = guardar("");` para que quede claro que fue a propósito.

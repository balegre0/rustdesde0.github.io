Una función no es solo algo que se llama: también es un **valor**. Se puede guardar en una variable, meter en un array, pasar a otra función o devolver. Es la base de las closures del mundo 14.

## La idea

El tipo de una función se escribe con `fn`, sus parámetros y su resultado:

```rust
fn aplicar_dos_veces(f: fn(i32) -> i32, x: i32) -> i32 { f(f(x)) }
```

`fn(i32) -> i32` es un **puntero a función**: «la dirección de alguna función que recibe un `i32` y devuelve un `i32`». Para pasar una función se escribe su nombre **sin paréntesis**: `aplicar_dos_veces(doble, 3)`. Con paréntesis la llamarías.

También se pueden **devolver**: una función puede elegir qué operación hacer y devolverla.

## Bajo el capó

<BajoElCapo>

**Elemento función y puntero a función no son lo mismo.** Cada función tiene su **propio tipo**, de tamaño cero (`let f = doble;`), que ya sabe exactamente qué función es: llamarlo es una llamada directa que el compilador puede expandir en línea. Al convertirlo a `fn(i32) -> i32` se pierde esa información: queda una **dirección**, y la llamada es indirecta.

<Ejecutar ej="m05/fn-item-tamano" />

**Por qué importa.** Cuando el compilador sabe exactamente qué función se llama (un elemento función), puede expandirla en línea: `doble(doble(x))` acaba siendo `x * 4`. Con un puntero cuyo valor no conoce, el procesador tiene que saltar a una dirección leída de memoria (aunque el optimizador, si ve de dónde viene el puntero, a veces también lo resuelve). En el mundo 14 verás que las closures funcionan como los elementos función: cada una tiene su tipo, y por eso son tan rápidas.

</BajoElCapo>

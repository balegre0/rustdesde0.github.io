Escribir `std::collections::HashMap` cada vez que quieres un mapa es agotador. `use` es el atajo, y `pub use` es la forma de diseñar qué ve quien usa tu código.

## La idea

`use ruta::nombre;` trae `nombre` al ámbito actual. Algunas formas:

```rust
use std::collections::HashMap;          // un nombre
use std::io::{self, Write};             // varios a la vez; `self` es `std::io`
use geometria::formas::area_circulo as area;   // con otro nombre
use std::fmt::Write as _;               // un trait, solo para usar sus métodos
use std::collections::*;                // todo (glob): úsalo poco
```

Tres detalles importantes:

1. **`use` no copia ni ejecuta nada.** Solo crea un **atajo** de nombre en ese módulo.
2. **Los traits se importan para usar sus métodos.** `writeln!(salida, …)` llama al método `write_fmt` del trait `Write`. Si `Write` no está en el ámbito, no compila.
3. **El atajo es local al módulo.** Un `use` en `main.rs` no vale dentro de `mod cocina { … }`. Cada módulo pone sus propios `use`.

**`pub use`** re-exporta: el nombre se puede usar desde fuera como si estuviera definido ahí. Las bibliotecas lo usan para ofrecer una ruta corta y cómoda aunque el código esté organizado en muchos módulos internos.

## Bajo el capó

<BajoElCapo>

**El preludio.** Hay nombres que usas sin `use`: `Vec`, `String`, `Option`, `Some`, `Ok`, `Box`, `println!`… Están en el **preludio** (`std::prelude::rust_2024`), una lista de `use` que el compilador pone automáticamente al principio de cada módulo. Cada edición tiene el suyo: el de 2021 añadió `TryFrom`, `TryInto` y `FromIterator`, y el de 2024 añadió `Future` e `IntoFuture`.

**`use` en funciones.** Se puede escribir `use` dentro de una función o de un bloque: el atajo vale solo ahí. Es útil para un `use Enum::*;` antes de un `match` largo.

</BajoElCapo>

## Trampa típica

<Trampa titulo="Importar con * todo lo que hay">

❌ `use std::collections::*;` o `use mi_crate::*;` en todas partes. Al leer el código no sabes de dónde viene cada nombre, y una versión nueva del crate puede añadir nombres que choquen con los tuyos.

✅ Importa nombres concretos. El glob está bien en casos acotados: en los tests (`use super::*;`, mundo 16) y en preludios pensados para ello.

</Trampa>

Un módulo es una caja con nombre para agrupar código relacionado. Ya has usado muchos sin saberlo: `std::collections` es un módulo de la biblioteca estándar, y `HashMap` vive dentro.

## La idea

`mod nombre { … }` crea un **módulo**. Dentro puedes poner funciones, structs, enums, constantes y otros módulos. Todos los módulos de un crate forman un **árbol**, cuya raíz es el propio crate (el archivo `main.rs`):

```text
crate                  ← main.rs
└── cocina
    ├── preparar()
    ├── horno
    │   └── hornear()
    └── salsas
        └── la_de_la_casa()
```

Para nombrar algo del árbol se escribe su **ruta**, con `::` entre piezas:

- **Absoluta**: desde la raíz, empezando por `crate::`. Ejemplo: `crate::cocina::salsas::la_de_la_casa()`.
- **Relativa**: desde donde estás. Ejemplo: `cocina::salsas::la_de_la_casa()` desde `main`, u `horno::hornear()` desde dentro de `cocina`.
- `self::` es el módulo actual y `super::` es el padre.

Para usar algo de **otro** módulo, tiene que ser **público** (`pub`). Por ahora, pon `pub` delante de lo que quieras usar desde fuera; la próxima lección lo explica a fondo.

## Bajo el capó

<BajoElCapo>

**Los módulos no existen al ejecutar.** Son solo una forma de organizar los **nombres**. Al compilar, cada función recibe un nombre único que incluye su ruta (y un código de comprobación): por ejemplo, `hornear` acaba llamándose algo como `_ZN4main6cocina5horno7hornear17h…E`. Esto se llama *mangling*. Por eso dos funciones `hornear` en módulos distintos no chocan.

**Resolución de nombres.** Antes de comprobar tipos, el compilador recorre el árbol de módulos y decide a qué elemento se refiere cada ruta. Si una ruta no lleva a nada, verás E0433 o E0425. Lo verás en el mundo 21, en la fase *name resolution*.

</BajoElCapo>

## Trampa típica

<Trampa titulo="Confundir la ruta relativa desde dentro de un módulo">

Dentro de `cocina`, escribir `cocina::horno::hornear()` **no** funciona: buscaría un módulo `cocina` dentro de `cocina`. Las rutas relativas empiezan en el módulo donde estás.

✅ Desde dentro de `cocina`: `horno::hornear()` o `self::horno::hornear()`. Desde cualquier sitio: `crate::cocina::horno::hornear()`.

</Trampa>

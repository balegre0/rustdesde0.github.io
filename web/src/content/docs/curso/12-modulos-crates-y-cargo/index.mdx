Hasta ahora todo tu código cabía en un `main.rs`. Los programas de verdad tienen miles de líneas, repartidas en muchos archivos y apoyadas en bibliotecas de otros. Este mundo trata de **organizar**: quién puede ver qué, cómo se nombra cada cosa y cómo Cargo junta las piezas.

Tres palabras que vas a usar todo el rato:

| Palabra | Qué es |
|---|---|
| **Módulo** | Un espacio de nombres dentro de un crate (`mod cocina { … }`). Controla qué es visible desde fuera. |
| **Crate** | La unidad que compila `rustc` de una vez: un ejecutable o una biblioteca. |
| **Paquete** | Lo que crea `cargo new`: un `Cargo.toml` con uno o varios crates. |

La idea de fondo es una sola: **todo es privado salvo que digas lo contrario**. Así puedes cambiar el interior de un módulo sin romper el código que lo usa, porque ese código solo ve lo que marcaste como `pub`.

## Lo que el compilador vigila en este mundo

| Error | Qué te impide hacer |
|---|---|
| [E0603](/errores/e0603/) | Usar un elemento privado desde fuera de su módulo |
| [E0616](/errores/e0616/) | Leer o escribir un campo privado de un struct |
| [E0432](/errores/e0432/) | Importar con `use` algo que no existe en esa ruta |
| [E0433](/errores/e0433/) | Usar una ruta con un módulo o crate que no se encuentra |

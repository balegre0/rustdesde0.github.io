Tu núcleo de juguete es el primer paso. En el mundo real, Rust ya forma parte de los sistemas operativos que usa casi todo el mundo.

## Linux

**Rust for Linux** es el proyecto (fundado por Miguel Ojeda en 2020) que permite escribir código del núcleo de Linux en Rust. Entró en la rama principal con **Linux 6.1** (diciembre de 2022) como experimento. Desde entonces:

- Se escriben en Rust, sobre todo, **controladores** (*drivers*): por ejemplo, los nuevos drivers de gráficos Nova (NVIDIA) y Tyr (Mali), o un driver de red PHY.
- **Android 16**, con el núcleo 6.12, incluye en producción el asignador de memoria compartida **ashmem** escrito en Rust: millones de dispositivos ya ejecutan Rust en el núcleo.
- En 2025, los mantenedores decidieron que Rust **deja de ser un experimento**: la documentación del núcleo lo refleja desde Linux 7.0. Todavía no funciona en todas las arquitecturas ni configuraciones, y la compilación con GCC (gccrs) sigue incompleta.

**Cómo se integra.** El código del núcleo existente está escrito en otro lenguaje. Rust for Linux crea **abstracciones seguras**: tipos de Rust que envuelven las estructuras y funciones del núcleo, con su `unsafe` revisado una vez, para que cada driver pueda escribirse casi sin `unsafe`. Es la misma idea de `split_at_mut` (mundo 07) a escala de un sistema operativo.

## Windows y Android

- Microsoft ha reescrito partes del núcleo de Windows en Rust (por ejemplo, componentes de `win32k`) y publica `windows-drivers-rs` para escribir drivers.
- En Android, Google escribe en Rust gran parte del código nuevo de sistema (Bluetooth, binder, componentes de seguridad), y atribuye a ello la caída de las vulnerabilidades de memoria en la plataforma.

## Sistemas operativos escritos en Rust

- **Redox**: un sistema tipo Unix con micronúcleo, entorno gráfico y su propia biblioteca de sistema.
- **Theseus**: un sistema de investigación que usa el sistema de tipos de Rust para aislar componentes.
- **Tock**: un sistema operativo para microcontroladores, con aplicaciones aisladas entre sí.
- **Hubris** (Oxide Computer): un núcleo pequeño para el firmware de servidores.

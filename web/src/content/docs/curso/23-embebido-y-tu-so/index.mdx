Hasta ahora, debajo de tus programas siempre había un sistema operativo: él cargaba el programa, le daba memoria, archivos e hilos. En este mundo lo quitas. Vas a programar **directamente el hardware**: primero un microcontrolador (un ordenador diminuto de unos pocos euros) y después **tu propio núcleo** de sistema operativo para PC.

Es el lugar donde se ve mejor por qué Rust es especial: las mismas garantías de memoria, sin sistema operativo, sin recolector de basura y sin coste.

:::note[Sin placa también se puede]
Los ejemplos de este mundo **simulan** el hardware para que se ejecuten aquí. Para la parte real, puedes usar el simulador **Wokwi** (en el navegador) o **QEMU** (en tu PC) antes de comprar una placa. La recomendada para empezar es la **micro:bit v2** (unos 20 €), la que usa el libro oficial *Discovery*.
:::

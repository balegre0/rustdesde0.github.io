La segunda parte de este mundo sigue el camino de **blog_os** (*Writing an OS in Rust*, de Philipp Oppermann), la serie más conocida para escribir un sistema operativo en Rust. Aquí tienes el mapa y las ideas de cada paso; el código completo y actualizado está en la serie.

## La idea

Un núcleo es un programa al que **nadie le da nada**: ni `main`, ni consola, ni memoria. El binario mínimo:

```rust
#![no_std]   // sin biblioteca estándar
#![no_main]  // sin el punto de entrada habitual

use core::panic::PanicInfo;

#[unsafe(no_mangle)]                 // el cargador busca el símbolo «_start»
pub extern "C" fn _start() -> ! {
    loop {}                          // un núcleo no termina
}

#[panic_handler]
fn panic(_info: &PanicInfo) -> ! {
    loop {}
}
```

Se compila para **`x86_64-unknown-none`**: procesador de PC, sin sistema operativo. Ese target viene con Rust (`rustup target add x86_64-unknown-none`) y se enlaza con `rust-lld`.

Para arrancarlo hace falta un **cargador de arranque** (*bootloader*): el crate `bootloader` (el que usa blog_os) prepara la CPU, crea una imagen de disco y salta a tu `_start`. Con **QEMU** (`qemu-system-x86_64 -drive format=raw,file=imagen.img`) lo pruebas sin reiniciar tu PC.

## El camino de blog_os

| Bloque | Pasos |
|---|---|
| Lo básico | binario autónomo · núcleo mínimo · texto en pantalla (VGA) · pruebas |
| Interrupciones | excepciones de la CPU · fallos dobles · interrupciones del hardware (teclado, temporizador) |
| Memoria | paginación · implementación de la paginación · el heap · diseños de asignadores |
| Multitarea | async/await con un ejecutor propio |

Las lecciones siguientes explican la idea de cada bloque con un ejemplo que puedes ejecutar.

## Bajo el capó

<BajoElCapo>

**Por qué `extern "C"` y `no_mangle`.** El cargador no sabe nada de Rust: salta a una dirección que encuentra buscando el símbolo `_start`, y llama con la convención de C. `no_mangle` hace que el símbolo se llame así de verdad.

**`-> !`.** Un núcleo no tiene a quién volver. El tipo `!` lo deja escrito, y el compilador comprueba que la función de verdad no termina.

**Pánico = abortar.** Sin `std` no hay desenrollado de pila. En `Cargo.toml` se pone `panic = "abort"` en los dos perfiles.

</BajoElCapo>

Hasta aquí todo se podía simular. Esta lección es el puente con el hardware real, y funciona perfectamente desde Windows, **incluso sin las Build Tools de Visual Studio**.

## Paso a paso (micro:bit v2)

1. **Instala el target** del procesador de la placa:

   ```powershell
   rustup target add thumbv7em-none-eabihf
   ```

2. **Instala probe-rs**, que graba y depura (la página oficial, probe.rs, tiene el instalador para Windows).

3. **Configura el proyecto** en `.cargo/config.toml`:

   ```toml
   [build]
   target = "thumbv7em-none-eabihf"

   [target.thumbv7em-none-eabihf]
   runner = "probe-rs run --chip nRF52833_xxAA"
   ```

4. Un `memory.x` con el mapa de memoria del chip (flash y RAM) y las dependencias de tu HAL o de Embassy, siguiendo la plantilla del libro *Discovery* o de los ejemplos de Embassy.

5. Conecta la placa por USB y:

   ```powershell
   cargo run --release
   ```

   Cargo compila, `rust-lld` enlaza, probe-rs graba el programa y muestra lo que la placa envíe.

## Ver lo que pasa dentro

- **defmt**: `defmt::info!("temperatura: {}", t)`. El texto no viaja a la placa: se queda en el ejecutable de tu PC y la placa envía solo un índice y los valores. Ocupa muy poco y es rapidísimo. probe-rs lo muestra en tu terminal.
- **Depurador**: probe-rs funciona con el depurador de VS Code (extensión *probe-rs-debugger*): puntos de ruptura, variables y registros en la placa real.

## Sin placa

- **Wokwi** simula placas (Raspberry Pi Pico, ESP32 y otras) en el navegador o en VS Code, con LEDs, botones y pantallas.
- **QEMU** emula microcontroladores ARM Cortex-M y un PC completo (lo usarás en la parte 2).

## La idea

Un **entero sin signo** (*unsigned integer*) es exactamente el binario de la lección 4: N bits, cada posición vale el doble que la anterior, y no hay negativos. Rust los llama con una `u` y el número de bits: `u8`, `u16`, `u32`, `u64` y `u128`. Hay uno más, `usize`, que mide lo que una dirección (4 bytes en el navegador, 8 en un PC de 64 bits).

Con N bits caben los números del **0 al 2ᴺ − 1**. El mínimo tiene todos los bits a 0; el máximo, todos a 1.

| Tipo | Bits | Máximo |
|---|---|---|
| `u8` | 8 | 255 |
| `u16` | 16 | 65 535 |
| `u32` | 32 | 4 294 967 295 |
| `u64` | 64 | 18 446 744 073 709 551 615 |

## Pruébalo

<Ejecutar ej="m01/sin-signo" />

Salida real:

```text
u8:  de 0 a 255
u16: de 0 a 65535
u32: de 0 a 4294967295
u64: de 0 a 18446744073709551615
10000001 = 128 + 1 = 129
u8::MAX en binario: 11111111
u16::MAX en hex:    0xffff
```

¿Y si una suma no cabe? Este adelanto usa dos formas explícitas de sumar. `checked_add` («suma comprobada») responde `None` si no cabe. `wrapping_add` («suma con vuelta») tira el bit que sobra:

<Ejecutar ej="m01/no-cabe" />

Salida real:

```text
255 + 1 comprobado:  None
255 + 1 con vuelta:  0
en bits: 11111111 + 1 = 100000000
```

255 + 1 = 256 necesita **9 bits** (`1` y ocho `0`). En un `u8` solo hay sitio para 8, así que el 1 de delante se pierde y queda 0. A esto se le llama **desbordamiento** (*overflow*). Lo que hace Rust con un `+` normal cuando pasa esto lo verás en el Mundo 3.

## Bajo el capó

<BajoElCapo>

Para la CPU, «sin signo» no es una propiedad de los bits: es una forma de **leerlos**. Un registro de 32 bits guarda 32 ceros y unos, y es la instrucción la que decide si los trata como sin signo o con signo. Rust lleva la cuenta por ti: como sabe el tipo de cada valor, elige las instrucciones correctas al compilar.

¿Por qué hay tantos tamaños? Porque cada uno ocupa lo que ocupa. Un `u8` gasta 1 byte; un `u64`, 8. Si guardas un millón de edades (que nunca pasan de 255), un `u8` gasta un millón de bytes y un `u64` ocho millones. Elegir el tipo es elegir cuánto espacio y qué rango necesitas.

`usize` es el tipo de los **índices** y de las **longitudes**: como mide lo que una dirección, siempre puede contar todos los bytes que la máquina puede numerar.

</BajoElCapo>

## Trampa típica

<Trampa titulo="«256 cabe en un byte»">

❌ «Un byte tiene 256 valores, así que el 256 cabe.»

✅ Los 256 valores son **del 0 al 255**. El 256 ya necesita 9 bits: no cabe en un `u8`. Es el mismo error que creer que con dos cifras decimales puedes escribir el 100.

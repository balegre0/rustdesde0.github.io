## La idea

Rust tiene doce tipos de enteros. El nombre te dice todo: la letra indica si hay signo y el número cuántos **bits** ocupa.

| Bits | Sin signo (`u`, *unsigned*) | Con signo (`i`, *integer*) |
|---|---|---|
| 8 | `u8` | `i8` |
| 16 | `u16` | `i16` |
| 32 | `u32` | `i32` |
| 64 | `u64` | `i64` |
| 128 | `u128` | `i128` |
| tamaño de una dirección | `usize` | `isize` |

Los `u` guardan solo 0 y positivos (binario puro). Los `i` usan **complemento a dos**, así que tienen un negativo más que positivos. Si no dices nada, un literal entero es `i32`.

`usize` e `isize` son especiales: miden lo que mide una **dirección de memoria** en la máquina donde corre el programa. Por eso son los tipos de los índices y de las longitudes (`len()` devuelve un `usize`). En tu PC de 64 bits miden 8 bytes; en el navegador, que ejecuta WebAssembly de 32 bits, miden **4**.

Para escribir números puedes usar `_` como separador (`1_000_000`), otras bases (`0xff` hexadecimal, `0b1010` binario, `0o17` octal) y un **sufijo** que fija el tipo (`5u8`, `7_i64`). Y `b'A'` es el byte de la letra A, un `u8`.

## Bajo el capó

<BajoElCapo titulo="La división, el resto y el bit de signo">
Las dos reglas de la división entera vienen de una sola ecuación que Rust garantiza: **`(a / b) * b + (a % b) == a`**. Si `-7 / 2` es `-3` (redondeo hacia el cero), entonces el resto tiene que ser `-7 − (−3 × 2) = −1`. Por eso `%` lleva el signo del **dividendo** (el de la izquierda). La salida real del ejemplo:

```text
7 / 2 = 3
-7 / 2 = -3
7 % 3 = 1
-7 % 3 = -1
-7
```

La última línea comprueba la ecuación con `a = -7` y `b = 3`: da `-7`.

¿Y por qué hay tantos tamaños? Porque cada uno es una caja de bytes de verdad en la memoria. Un array de un millón de `u8` ocupa 1 MB; de `u64`, 8 MB. Elegir bien el tipo es elegir cuánta memoria usas y qué rango aceptas. Como regla práctica: `i32` para números en general, `usize` para índices y tamaños, `u8` para bytes, y `u64`/`i64` cuando un `i32` se queda corto.

## Trampa típica

<Trampa titulo="Dividir entre cero">
❌ Dividir un entero entre cero. No hay ningún número que sea «10 entre 0», así que Rust no se inventa uno. Si el compilador lo ve venir con valores fijos, se niega a compilar. Error real al compilar `let a = 10; let b = 0; println!("{}", a / b);`:

```text
error: this operation will panic at runtime
 --> ejemplos/m03/div-cero.rs:4:20
  |
4 |     println!("{}", a / b);
  |                    ^^^^^ attempt to divide `10_i32` by zero
  |
  = note: `#[deny(unconditional_panic)]` on by default
```

«Esta operación entrará en pánico al ejecutarse». Si el divisor llega en tiempo de ejecución (por ejemplo, lo escribe el usuario), el programa se detiene con un **pánico** (*panic*): un fallo controlado con mensaje.

✅ Comprueba el divisor antes de dividir, o usa `checked_div`, que devuelve «nada» en lugar de fallar (lo verás en la lección 6).
</Trampa>

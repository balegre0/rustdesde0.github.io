Una tupla agrupa unos pocos valores distintos. Cuando tienes **muchos** valores del **mismo** tipo (las notas de una clase, los píxeles de una fila), usas un **array**. Hoy vas a ver también la primera vez que Rust te protege de leer memoria que no es tuya.

## La idea

Un **array** es una fila de `N` valores del **mismo tipo**, uno detrás de otro. Su tipo se escribe `[T; N]`: `[i32; 4]` es «cuatro `i32`». Se crea de dos formas:

```rust
let notas = [7, 9, 5, 10];   // enumerando los valores
let ceros = [0u8; 5];        // [valor; cuántos]
```

Los elementos se leen por **índice** (*index*), empezando en 0: `notas[0]` es el primero y `notas[notas.len() - 1]` el último. `len()` devuelve la longitud como `usize`.

El tamaño `N` es **parte del tipo** y no puede cambiar: `[i32; 4]` y `[i32; 5]` son tipos distintos. Con `mut` puedes cambiar los elementos, pero no añadir ni quitar. Para filas que crecen está `Vec`, que verás en el Mundo 11.

## Bajo el capó

<BajoElCapo titulo="Un array en la pila, y la comprobación de límites">
Un array guarda sus elementos **contiguos**: `[i32; 4]` son 16 bytes seguidos, sin nada más (ni siquiera la longitud: la longitud está en el **tipo**, la conoce el compilador). Como una variable local, vive en la **pila**. El elemento `i` está en la dirección «inicio + i × 4».

Esa fórmula funciona para cualquier `i`, también para 3, 1000 o un millón: la CPU calcularía una dirección fuera del array y leería lo que hubiera allí, quizá otra variable. Es el error de memoria más clásico, el **acceso fuera de límites** (*out-of-bounds*). Rust lo impide comprobando `i < len` antes de **cada** acceso con `[]`: si no se cumple, pánico. El coste es una comparación, y el optimizador la elimina cuando puede demostrar que el índice siempre es válido.

Si el índice es una constante, ni siquiera hace falta ejecutar. Error real al compilar `let notas = [7, 9, 5]; println!("{}", notas[3]);`:

```text
error: this operation will panic at runtime
 --> ejemplos/m03/fuera-constante.rs:3:20
  |
3 |     println!("{}", notas[3]);
  |                    ^^^^^^^^ index out of bounds: the length is 3 but the index is 3
  |
  = note: `#[deny(unconditional_panic)]` on by default
```
</BajoElCapo>

## Trampa típica

Un array exige que todos sus elementos sean del mismo tipo:

<NoCompila ej="m03/array-tipos" explicacion="E0308: el primer elemento, `1`, fija que el array es de enteros; `2.5` es un decimal. Escribe todos como decimales (`1.0`, `2.5`, `3.0`) o usa una tupla si de verdad quieres mezclar tipos." />

<Trampa titulo="El último elemento no es notas[notas.len()]">
❌ `notas[notas.len()]` para leer el último: con 3 elementos, eso es `notas[3]`, fuera del array.

✅ `notas[notas.len() - 1]`. Los índices van de 0 a `len - 1`.
</Trampa>

Ya tienes el taller montado. Vas a crear tu primer proyecto de Rust, ver qué hay dentro y ejecutarlo.

## La idea

**Cargo** crea y gestiona proyectos. Un proyecto de Cargo se llama **paquete** (*package*) y es una carpeta con una estructura fija. Para crear uno:

```powershell
cd C:\dev
cargo new hola
cd hola
```

Cargo crea esto:

```text
hola\
├── Cargo.toml      ← el manifiesto: nombre, versión, edición, dependencias
├── .gitignore      ← le dice a Git que ignore la carpeta target
└── src\
    └── main.rs     ← tu código
```

Y `src\main.rs` ya trae un programa:

<Ejecutar ej="m00/hola" />

Para compilarlo y ejecutarlo:

```powershell
cargo run
```

```text
   Compiling hola v0.1.0 (C:\dev\hola)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.61s
     Running `target\debug\hola.exe`
Hello, world!
```

Las tres primeras líneas son de Cargo: compiló el paquete, en el perfil `dev`, y ejecutó `target\debug\hola.exe`. La cuarta es **tu programa**. Si vuelves a ejecutar `cargo run` sin cambiar nada, no recompila: va directo a ejecutar.

## Qué es cada cosa

En el mundo 02 verás `fn main` y `println!` con detalle. De momento:

- `fn main() { … }` es el punto de entrada: el programa empieza aquí.
- `println!("…")` imprime un texto y salta de línea. El `!` indica que es una **macro**, no una función normal (mundo 02).
- Cada instrucción termina en `;`.

<Trampa titulo="Ejecutar cargo run en la carpeta equivocada">

```text
error: could not find `Cargo.toml` in `C:\dev` or any parent directory
```

Estás en `C:\dev`, no dentro del proyecto. Cargo busca `Cargo.toml` en la carpeta actual y en las de arriba, nunca en las de abajo.

✅ `cd hola` y vuelve a probar.

</Trampa>

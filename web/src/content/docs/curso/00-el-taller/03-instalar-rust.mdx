Vas a instalar Rust en tu PC. Son unos minutos, pero conviene entender **qué** instalas, porque la próxima lección depende de ello.

## La idea

Rust no se instala como un programa normal, sino con **rustup**, un gestor que instala y mantiene al día todas las herramientas:

| Herramienta | Qué hace |
|---|---|
| `rustc` | el **compilador**: convierte tu código en un programa ejecutable |
| `cargo` | el **gestor de proyectos**: crea proyectos, compila, ejecuta, prueba, descarga bibliotecas |
| la biblioteca estándar (`std`) | el código que viene con Rust: textos, listas, archivos… |
| `rustfmt`, `clippy` | el formateador y el revisor de estilo (mundo 16) |

Un juego completo de estas herramientas, de una versión concreta, se llama **toolchain**. La que instalarás se llama `stable-x86_64-pc-windows-msvc`:

- `stable`: la versión estable (sale una nueva cada 6 semanas; en este curso, la **1.99**).
- `x86_64-pc-windows`: para procesadores de 64 bits con Windows.
- `msvc`: los programas se **enlazan** con las herramientas de Microsoft. Esto es importante en la lección siguiente.

## Instálalo

1. Abre **Terminal** (PowerShell) y escribe:

   ```powershell
   winget install --id Rustlang.Rustup
   ```

   Si no tienes `winget`, descarga `rustup-init.exe` desde la web oficial, **rustup.rs**, y ejecútalo.

2. Si el instalador te ofrece instalar los requisitos de Visual Studio, **acepta**: es la solución de la próxima lección hecha por adelantado.

3. Acepta las opciones por defecto.

4. **Cierra la terminal y abre una nueva** (para que encuentre las órdenes nuevas) y comprueba:

   ```powershell
   rustc --version
   cargo --version
   rustup --version
   ```

   Deberías ver algo como `rustc 1.99.1 (… 2026-10-13)`. El número puede ser mayor si lees esto más tarde: no importa.

## Mantenerlo

```powershell
rustup update           # actualiza a la última versión estable
rustup show             # muestra qué toolchain usas
rustup doc --book       # abre el libro oficial de Rust, sin conexión
```

`rustup doc` merece la pena: toda la documentación de la biblioteca estándar, en tu PC, aunque no tengas internet.

<Trampa titulo="«rustc no se reconoce como un comando»">

Si al escribir `rustc --version` aparece *«El término 'rustc' no se reconoce…»*, casi siempre es porque la terminal se abrió **antes** de instalar. El instalador añade `%USERPROFILE%\.cargo\bin` al PATH (la lista de carpetas donde Windows busca programas), pero las terminales ya abiertas no se enteran.

✅ Cierra **todas** las terminales (y el editor, si tiene una dentro) y abre una nueva.

</Trampa>

Vas a romper tu código. Muchas veces. Git hace que no importe: guarda **fotos** de tu proyecto y te deja volver a cualquiera de ellas.

## La idea

**Git** es un sistema de **control de versiones**: guarda la historia de los cambios de una carpeta. Cada foto guardada se llama **commit** y lleva un mensaje que explica qué cambió.

`cargo new` ya creó un **repositorio** de Git en tu proyecto (por eso existe `.gitignore`). Solo necesitas instalar Git:

```powershell
winget install --id Git.Git
```

y decirle quién eres (una sola vez):

```powershell
git config --global user.name "Tu nombre"
git config --global user.email "tu@correo.com"
```

## Las cinco órdenes

```powershell
git status                        # ¿qué ha cambiado desde la última foto?
git add .                         # prepara todos los cambios para la foto
git commit -m "Saludo en español" # hace la foto, con un mensaje
git log --oneline                 # la historia de fotos
git diff                          # qué líneas has cambiado (antes de add)
```

El ritmo de trabajo es: **cambiar → probar → `add` → `commit`**. Haz un commit cada vez que algo funcione, aunque sea pequeño. Un buen mensaje dice **qué** hace el cambio: «Pide el nombre al usuario», no «cambios».

Si estropeas un archivo y quieres volver a como estaba en el último commit:

```powershell
git restore src\main.rs
```

## Pruébalo

En tu proyecto `hola`:

1. `git status`: verás `Cargo.toml` y `src/` como nuevos (*untracked*).
2. `git add .` y `git commit -m "Proyecto inicial"`.
3. Cambia el texto de `main.rs`. `git diff` te mostrará la línea quitada (−) y la añadida (+).
4. `git commit -am "Saludo en español"` (`-a` añade los archivos ya conocidos).
5. `git log --oneline`: dos fotos.

Fíjate en que `target` nunca aparece en `git status`: el `.gitignore` la excluye.

<Trampa titulo="Commits gigantes">

❌ Trabajar una tarde entera y hacer un solo commit «todo». Si algo se rompió por el camino, no sabrás cuándo.

✅ Commits pequeños y frecuentes. Si un cambio rompe algo, vuelves al commit anterior y has perdido cinco minutos, no una tarde.

</Trampa>

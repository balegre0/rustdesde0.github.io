> **Mensaje de rustc:** `` only traits defined in the current crate can be implemented for types defined outside of the crate ``

## Qué significa

La **regla huérfana** (*orphan rule*) dice: para escribir `impl Trait for Tipo`, el trait **o** el tipo deben ser de tu crate. `Display` y `Vec<u8>` son los dos de la biblioteca estándar. Si se permitiera, dos crates distintos podrían implementar lo mismo de forma diferente y nadie sabría cuál usar.

## Ejemplo que lo provoca

<NoCompila ej="errores/E0117" />

**Error real** (rustc 1.99.1, edición 2024):

```text
error[E0117]: only traits defined in the current crate can be implemented for types defined outside of the crate
 --> E0117.rs:3:1
  |
3 | impl fmt::Display for Vec<u8> {
  | ^^^^^^^^^^^^^^^^^^^^^^-------
  |                       |
  |                       `Vec` is not defined in the current crate
  |
  = note: impl doesn't have any local type before any uncovered type parameters
  = note: for more information see https://doc.rust-lang.org/reference/items/implementations.html#orphan-rules
  = note: define and implement a trait or new type instead
```

Cómo leerlo: la primera línea dice **qué** pasa; `-->` dice **dónde** (archivo, línea y columna); las marcas `^` y `-` señalan las piezas implicadas, y `help:` propone un arreglo. Léelo siempre de arriba abajo.

## Causas típicas

- Implementar `Display`, `From` u otro trait estándar para `Vec`, `String`, `Option`…
- Implementar un trait de un crate externo para un tipo de otro crate externo.

## Cómo arreglarlo

Envuelve el tipo en uno tuyo (**patrón newtype**): `struct Bytes(Vec<u8>);` y implementa el trait para `Bytes`. O define tu propio trait.

Así queda el ejemplo arreglado (botón «Ver arreglo» arriba):

```rust
use std::fmt;

struct Bytes(Vec<u8>); // tipo nuevo y local: le puedes implementar lo que quieras

impl fmt::Display for Bytes {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "{} bytes", self.0.len())
    }
}

fn main() {
    println!("{}", Bytes(vec![1, 2, 3]));
}
```

**Salida:**

```text
3 bytes
```

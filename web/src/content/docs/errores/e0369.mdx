> **Mensaje de rustc:** `` cannot add `Dinero` to `Dinero` ``

## Qué significa

Los operadores son traits: `a + b` es `Add::add(a, b)`; `==` es `PartialEq`; `<` es `PartialOrd`. Un struct propio no tiene ninguno de ellos hasta que lo implementas o lo derivas.

Cómo leerlo: la primera línea dice **qué** pasa; `-->` dice **dónde** (archivo, línea y columna); las marcas `^` y `-` señalan las piezas implicadas, y `help:` propone un arreglo. Léelo siempre de arriba abajo.

## Causas típicas

- Sumar dos structs propios.
- Comparar con `==` tipos que no implementan `PartialEq`.
- Concatenar dos `&str` con `+` (hace falta un `String` a la izquierda).

## Cómo arreglarlo

Implementa el trait del operador (`impl Add for Dinero`), o deriva los de comparación (`#[derive(PartialEq, PartialOrd)]`). Para textos: `String::from(a) + b` o `format!("{a}{b}")`.

Así queda el ejemplo arreglado (botón «Ver arreglo» arriba):

```rust
use std::ops::Add;

struct Dinero {
    centimos: u64,
}

impl Add for Dinero {
    type Output = Dinero;
    fn add(self, otro: Dinero) -> Dinero {
        Dinero { centimos: self.centimos + otro.centimos }
    }
}

fn main() {
    let a = Dinero { centimos: 150 };
    let b = Dinero { centimos: 250 };
    let total = a + b;
    println!("{}", total.centimos);
}
```

**Salida:**

```text
400
```

> **Mensaje de rustc:** `` struct `Jugador` has no field named `edad` ``

## Qué significa

Solo puedes dar valor a los campos que declara el struct. `edad` no está en `Jugador`.

## Ejemplo que lo provoca

<NoCompila ej="errores/E0560" />

**Error real** (rustc 1.99.1, edición 2024):

```text
error[E0560]: struct `Jugador` has no field named `edad`
 --> E0560.rs:6:52
  |
6 |     let j = Jugador { nombre: String::from("Ana"), edad: 30 };
  |                                                    ^^^^ `Jugador` does not have this field
  |
  = note: all struct fields are already assigned
```

Cómo leerlo: la primera línea dice **qué** pasa; `-->` dice **dónde** (archivo, línea y columna); las marcas `^` y `-` señalan las piezas implicadas, y `help:` propone un arreglo. Léelo siempre de arriba abajo.

## Causas típicas

- Errata en el nombre del campo.
- Usar un campo que existía en otra versión del struct o en otro tipo.

## Cómo arreglarlo

Corrige el nombre o añade el campo a la definición.

Así queda el ejemplo arreglado (botón «Ver arreglo» arriba):

```rust
struct Jugador {
    nombre: String,
    edad: u32,
}

fn main() {
    let j = Jugador { nombre: String::from("Ana"), edad: 30 };
    println!("{} {}", j.nombre, j.edad);
}
```

**Salida:**

```text
Ana 30
```

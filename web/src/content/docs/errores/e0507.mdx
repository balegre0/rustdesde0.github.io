> **Mensaje de rustc:** `` cannot move out of `r.contenido` which is behind a shared reference ``

## Qué significa

Con `r: &Caja` solo **tomas prestada** la caja. `let sacado = r.contenido;` intentaría **mover** el `String` fuera de ella, quitándoselo a su dueño `c`. Un préstamo no da derecho a llevarse nada.

## Qué error evita

Si se permitiera, `c` seguiría creyendo que tiene su `String` y lo liberaría al final, igual que `sacado`: **doble liberación**.

## Ejemplo que lo provoca

**Error real** (rustc 1.99.1, edición 2024):

```text
error[E0507]: cannot move out of `r.contenido` which is behind a shared reference
 --> E0507.rs:8:18
  |
8 |     let sacado = r.contenido;
  |                  ^^^^^^^^^^^ move occurs because `r.contenido` has type `String`, which does not implement the `Copy` trait
  |
help: consider borrowing here
  |
8 |     let sacado = &r.contenido;
  |                  +
help: consider cloning the value if the performance cost is acceptable
  |
8 |     let sacado = r.contenido.clone();
  |                             ++++++++
```

Cómo leerlo: la primera línea dice **qué** pasa; `-->` dice **dónde** (archivo, línea y columna); las marcas `^` y `-` señalan las piezas implicadas, y `help:` propone un arreglo. Léelo siempre de arriba abajo.

## Causas típicas

- Leer un campo no `Copy` a través de `&self` o de `&T` (`self.nombre`).
- Sacar un elemento de un `Vec` con `v[i]` cuando el tipo no es `Copy`.
- Hacer `match` sobre `*referencia` con patrones que mueven.
- Usar dentro de una closure `Fn` una variable capturada como si fuera tuya.

## Cómo arreglarlo

Elige entre: **tomar prestado** (`&r.contenido`), **clonar** (`r.contenido.clone()`), o, si tienes `&mut`, **intercambiar**: `std::mem::take(&mut x.campo)` deja un valor por defecto en su lugar, `mem::replace` deja el que tú digas, y `Option::take()` deja `None`.

Así queda el ejemplo arreglado (botón «Ver arreglo» arriba):

```rust
struct Caja {
    contenido: String,
}

fn main() {
    let c = Caja { contenido: String::from("libro") };
    let r = &c;
    let sacado = &r.contenido; // tomar prestado en vez de mover
    println!("{sacado}");
}
```

**Salida:**

```text
libro
```

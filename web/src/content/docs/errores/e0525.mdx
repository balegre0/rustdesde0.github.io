> **Mensaje de rustc:** `` expected a closure that implements the `Fn` trait, but this closure only implements `FnOnce` ``

## Qué significa

Una closure que **mueve** fuera de sí un valor capturado (`let dueno = nombre;`) solo puede llamarse **una vez**: después ya no tiene ese valor. Por eso solo implementa `FnOnce`. `llamar_dos_veces` pide `F: Fn()`, es decir, una closure que se pueda llamar muchas veces sin gastarse.

Cómo leerlo: la primera línea dice **qué** pasa; `-->` dice **dónde** (archivo, línea y columna); las marcas `^` y `-` señalan las piezas implicadas, y `help:` propone un arreglo. Léelo siempre de arriba abajo.

## Causas típicas

- Mover o devolver dentro de la closure una variable capturada que no es `Copy`.
- Llamar dentro de la closure a una función que recibe el valor capturado por valor.

## Cómo arreglarlo

Haz que la closure solo **mire** lo capturado (`&nombre`) o que lo clone por dentro (`nombre.clone()`). Si de verdad solo se llama una vez, cambia el límite a `F: FnOnce()`.

Así queda el ejemplo arreglado (botón «Ver arreglo» arriba):

```rust
fn llamar_dos_veces<F: Fn()>(f: F) {
    f();
    f();
}

fn main() {
    let nombre = String::from("Ana");
    let despedir = move || {
        let prestado = &nombre; // solo lo mira: la closure es Fn
        println!("adiós, {prestado}");
    };
    llamar_dos_veces(despedir);
}
```

**Salida:**

```text
adiós, Ana
adiós, Ana
```

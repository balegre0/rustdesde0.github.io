> **Mensaje de rustc:** `` variable `n` is not bound in all patterns ``

## Qué significa

Con `A(t) | B(n) => ...`, el brazo se ejecuta para las dos alternativas. Si es `A`, existe `t` pero no `n`; si es `B`, al revés. El código del brazo no sabría qué variables existen. Por eso cada alternativa debe ligar **las mismas variables, con el mismo tipo**.

Cómo leerlo: la primera línea dice **qué** pasa; `-->` dice **dónde** (archivo, línea y columna); las marcas `^` y `-` señalan las piezas implicadas, y `help:` propone un arreglo. Léelo siempre de arriba abajo.

## Causas típicas

- Juntar con `|` variantes con datos distintos.
- Erratas en el nombre de la variable entre alternativas.

## Cómo arreglarlo

Separa los casos en brazos distintos, o usa el mismo nombre en todas las alternativas si los tipos coinciden, o ignora los datos con `_`.

Así queda el ejemplo arreglado (botón «Ver arreglo» arriba):

```rust
enum Mensaje {
    Texto(String),
    Numero(i32),
}

fn main() {
    for m in [Mensaje::Numero(4), Mensaje::Texto(String::from("hola"))] {
        match m {
            Mensaje::Texto(t) => println!("texto: {t}"),
            Mensaje::Numero(n) => println!("número: {n}"),
        }
    }
}
```

**Salida:**

```text
número: 4
texto: hola
```

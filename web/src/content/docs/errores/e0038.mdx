> **Mensaje de rustc:** `` the trait `Clonable` is not dyn compatible ``

## Qué significa

Un objeto de trait (`dyn Clonable`) oculta el tipo concreto: solo se sabe que «implementa el trait». Un método que devuelve `Self` necesita conocer ese tipo (y su tamaño) para devolverlo, así que no puede llamarse a través de `dyn`. Por eso el trait no es **compatible con dyn** (*dyn compatible*).


Cómo leerlo: la primera línea dice **qué** pasa; `-->` dice **dónde** (archivo, línea y columna); las marcas `^` y `-` señalan las piezas implicadas, y `help:` propone un arreglo. Léelo siempre de arriba abajo.

## Causas típicas

- Métodos que devuelven `Self` o lo reciben por valor.
- Métodos genéricos (`fn f<T>(&self, x: T)`).
- Traits que exigen `Sized` o `Clone` como supertrait.

## Cómo arreglarlo

Devuelve `Box<dyn Trait>` en lugar de `Self`, añade `where Self: Sized` a los métodos que no deben llamarse por `dyn`, o usa genéricos (`impl Trait`, `T: Trait`) en lugar de `dyn`.

Así queda el ejemplo arreglado (botón «Ver arreglo» arriba):

```rust
trait Clonable {
    fn duplicar(&self) -> Box<dyn Clonable>;
    fn mostrar(&self) -> String;
}

impl Clonable for i32 {
    fn duplicar(&self) -> Box<dyn Clonable> {
        Box::new(*self)
    }
    fn mostrar(&self) -> String {
        self.to_string()
    }
}

fn main() {
    let cosas: Vec<Box<dyn Clonable>> = vec![Box::new(1)];
    let copia = cosas[0].duplicar();
    println!("{} {}", cosas.len(), copia.mostrar());
}
```

**Salida:**

```text
1 1
```

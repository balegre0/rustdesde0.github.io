> **Mensaje de rustc:** `` type annotations needed ``

## Qué significa

`sum()` puede producir muchos tipos (`u32`, `u64`, `f64`…): cualquiera que implemente `Sum<u32>`. Como nada dice qué tipo es `total`, hay varias opciones válidas y rustc no elige por ti. Pasa igual con `collect()` (puede crear un `Vec`, un `String`, un `HashSet`…).

Cómo leerlo: la primera línea dice **qué** pasa; `-->` dice **dónde** (archivo, línea y columna); las marcas `^` y `-` señalan las piezas implicadas, y `help:` propone un arreglo. Léelo siempre de arriba abajo.

## Causas típicas

- `sum()`, `product()` o `collect()` sin tipo de destino.
- `into()` cuando hay varias conversiones posibles.

## Cómo arreglarlo

Anota la variable (`let total: u32 = ...`) o usa *turbofish*: `.sum::<u32>()`, `.collect::<Vec<_>>()`.

Así queda el ejemplo arreglado (botón «Ver arreglo» arriba):

```rust
fn main() {
    let total: u32 = "1 2 3".split(' ').map(|t| t.parse::<u32>().unwrap()).sum();
    println!("{total}");
}
```

**Salida:**

```text
6
```

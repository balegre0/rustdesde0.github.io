> **Mensaje de rustc:** `` cannot index into a value of type `u32` ``

## Qué significa

`valor[i]` solo funciona en tipos que implementan `Index`: arrays, slices, `Vec`, `String` (con rangos), `HashMap`… Un `u32` es un único número: no tiene «posición 0».

## Ejemplo que lo provoca

<NoCompila ej="errores/E0608" />

**Error real** (rustc 1.99.1, edición 2024):

```text
error[E0608]: cannot index into a value of type `u32`
 --> E0608.rs:3:24
  |
3 |     println!("{}", edad[0]);
  |                        ^^^
```

Cómo leerlo: la primera línea dice **qué** pasa; `-->` dice **dónde** (archivo, línea y columna); las marcas `^` y `-` señalan las piezas implicadas, y `help:` propone un arreglo. Léelo siempre de arriba abajo.

## Causas típicas

- Confundir una variable numérica con una lista.
- Indexar un `Option<Vec<T>>` sin sacar antes el `Vec`.
- Indexar un iterador (hay que usar `.nth(i)`).

## Cómo arreglarlo

Indexa la colección correcta, o usa el método adecuado (`.nth()` en iteradores, `.chars().nth()` en textos).

Así queda el ejemplo arreglado (botón «Ver arreglo» arriba):

```rust
fn main() {
    let edades: [u32; 2] = [30, 41];
    println!("{}", edades[0]);
}
```

**Salida:**

```text
30
```

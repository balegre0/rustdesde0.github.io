**Ruta:** `std::process`

## Para qué sirve

Cuando un programa termina, devuelve al sistema un **código de salida**: `0` significa «todo bien» y cualquier otro número, «algo falló». Este módulo permite elegir ese código (`ExitCode`, `exit`) y lanzar otros programas (`Command`).

## Contenido de un vistazo

| Nombre | Resumen | Desde |
|---|---|---|
| [`exit`](/ref/std/process/exit/) | Termina el programa ya, con un código. | 1.0 |
| `ExitCode` | Código de salida que `main` puede devolver. | 1.61 |
| `Command` | Prepara y lanza otro programa. | 1.0 |
| `abort` | Termina de golpe, sin limpiar nada. | 1.17 |
| `id` | El identificador del proceso. | 1.26 |

## Conceptos clave

- **Mejor devolver que salir**: `fn main() -> ExitCode` (o `-> Result<(), E>`) termina limpiamente, ejecutando los destructores. `exit` no los ejecuta.
- **Si `main` devuelve `Err`**, Rust muestra el error con `Debug` y sale con código `1`.
- **`Command` no funciona en el navegador** (no hay otros programas). En tu PC, `output()` lo ejecuta y recoge su salida.

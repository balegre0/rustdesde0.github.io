**Ruta:** `std::process::exit`

## Sinopsis

```rust
pub fn exit(code: i32) -> !
```

## Qué hace

`process::exit(codigo)` termina **ya**. Su tipo de retorno es `!` («nunca vuelve»), así que el compilador sabe que lo que va detrás no se ejecuta. **No ejecuta los destructores** de los valores vivos (los búferes de archivos sin vaciar, por ejemplo); `stdout` sí se vacía.

## Ejemplo

<Ejecutar ej="ref-std/process-exit" />

**Salida:**

```text
5
```

**Salida de error** (*stderr*):

```text
error: división por cero
```

El programa termina con el código de salida `2`.

Rust 1.0 (estable).

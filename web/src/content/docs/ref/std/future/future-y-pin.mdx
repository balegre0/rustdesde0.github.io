**Ruta:** `std::future::Future`, `std::task::{Poll, Context, Waker}`, `std::pin::{Pin, pin}`

## Sinopsis

```rust
pub trait Future {
    type Output;
    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Self::Output>;
}
pub enum Poll<T> { Ready(T), Pending }
macro_rules! pin { ($valor:expr $(,)?) => { … } } // -> Pin<&mut T>
```

## Qué hace

Una función `async` devuelve un **futuro**: un valor que representa un cálculo que todavía no se ha hecho. No avanza solo: alguien (un **ejecutor**) tiene que llamar a `poll`. Cada llamada devuelve `Poll::Ready(valor)` si terminó o `Poll::Pending` si tiene que esperar; en ese caso, el futuro guarda el `Waker` de `cx` para avisar cuando pueda seguir.

`poll` recibe `Pin<&mut Self>`: el futuro no se puede **mover** mientras se sondea, porque puede contener referencias a sus propios campos. `pin!` fija un valor en la pila y devuelve un `Pin<&mut T>` sin `unsafe`.

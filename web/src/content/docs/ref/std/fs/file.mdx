## Qué hace

`File` representa un archivo abierto. Implementa `Read` y `Write`, así que se usa con todo lo de `std::io`. `File::open` abre para leer; `File::create` crea (o vacía) para escribir; `OpenOptions` permite combinaciones (por ejemplo, añadir al final).

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`open`](#open) | Abre un archivo existente para leer. | 1.0 |
| [`create`](#create) | Crea un archivo para escribir, o lo vacía si existe. | 1.0 |
| [`options`](#options) | Atajo de `OpenOptions::new()`. | 1.58 |

| [`sync_all`](#sync_all) | Espera a que todo lo escrito llegue al disco. | 1.0 |

## Errores

`open` falla si el archivo no existe o no tienes permiso (el ejemplo muestra el mensaje del navegador; en Windows o Linux el texto y el número de error son otros). Mira `e.kind()` para distinguir casos: `NotFound`, `PermissionDenied`, `AlreadyExists`…

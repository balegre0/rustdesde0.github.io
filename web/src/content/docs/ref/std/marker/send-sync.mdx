**Ruta:** `std::marker::Send, std::marker::Sync` · está en el **preludio** (no necesita `use`)

## Sinopsis

```rust
pub unsafe auto trait Send { }

pub unsafe auto trait Sync { }
```

## Qué hace

- **`Send`**: se puede **mover** a otro hilo. Casi todo lo es. `Rc` no, porque su contador no es atómico: dos hilos con clones del mismo `Rc` podrían corromperlo.
- **`Sync`**: se puede **compartir** entre hilos con `&T`. Formalmente, `T` es `Sync` si `&T` es `Send`. `Cell` y `RefCell` no lo son (su modificación interior no está protegida); `Mutex<T>` sí.

`thread::spawn` exige `Send` a lo que se lleva el hilo; así el compilador rechaza el programa antes de que la carrera pueda ocurrir.

## Seguridad

Son `unsafe trait`: escribir `unsafe impl Send for MiTipo {}` es prometer que tu tipo es seguro entre hilos. Solo es necesario con punteros crudos u otros tipos que no los implementan automáticamente.

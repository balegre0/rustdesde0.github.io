**Ruta:** `std::marker::PhantomData`

## Sinopsis

```rust
pub struct PhantomData<T>
where
    T: ?Sized;
```

## Qué hace

`PhantomData<T>` ocupa **0 bytes**, pero el compilador razona como si tu tipo contuviera un `T`. Se usa para marcar tipos (unidades, estados), para que un parámetro genérico no quede sin usar ([E0392](/errores/e0392/)) y, en código `unsafe`, para indicar propiedad o tiempos de vida de datos a los que solo apuntas con punteros crudos (afecta a la varianza, a `Send`/`Sync` y al *drop check*).

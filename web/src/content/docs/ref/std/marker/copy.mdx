**Ruta:** `std::marker::Copy` · está en el **preludio** (no necesita `use`)

## Sinopsis

```rust
pub trait Copy: Clone { }
```

## Qué hace

Si un tipo es `Copy`, `let b = a;` **copia** el valor y `a` sigue siendo válida. Lo son los números, `bool`, `char`, las referencias compartidas `&T` y las tuplas y arrays de tipos `Copy`. Un tipo solo puede ser `Copy` si todos sus campos lo son ([E0204](/errores/e0204/)) y si no tiene `Drop` ([E0184](/errores/e0184/)). `Copy` exige `Clone`: se derivan juntos, `#[derive(Clone, Copy)]`.

**Ruta:** `std::marker::Sized` · está en el **preludio** (no necesita `use`)

## Sinopsis

```rust
pub trait Sized { }
```

## Qué hace

Casi todos los tipos son `Sized`. Los que no lo son (**tipos de tamaño dinámico**, DST) son `str`, `[T]` y `dyn Trait`: solo se pueden usar detrás de un puntero (`&str`, `Box<[T]>`, `&dyn Trait`), que entonces guarda también la longitud o el puntero a la vtable. Todo parámetro genérico lleva un `T: Sized` implícito; escribe `T: ?Sized` para aceptar también los DST.

## Ejemplo

<Ejecutar ej="ref-std/marker-sized" />

**Salida:**

```text

[hola] ocupa 4 bytes

```

**Ruta:** `std::mem`

## Para qué sirve

Funciones básicas para mirar y manipular **valores en memoria**: cuánto ocupan, intercambiarlos, sacarlos de detrás de un `&mut` dejando otro en su lugar, o evitar que se destruyan.

## Contenido de un vistazo

| Nombre | Resumen | Desde |
|---|---|---|
| [`size_of, size_of_val, align_of`](/ref/std/mem/size_of/) | Tamaño y alineación de un tipo o valor. | 1.0 |
| [`swap, replace, take`](/ref/std/mem/swap-replace-take/) | Intercambiar o sacar valores a través de `&mut`. | 1.0 |
| [`forget`](/ref/std/mem/forget/) | Olvidar un valor: no se ejecuta su destructor. | 1.0 |
| [`drop`](/ref/std/ops/drop/) | Destruir un valor ya (en el preludio). | None |
| `discriminant` | Qué variante de un enum es, sin mirar sus datos. | 1.21 |
| `transmute` | Reinterpretar los bits de un valor como otro tipo (`unsafe`). | 1.0 |
| `MaybeUninit, ManuallyDrop` | Memoria sin inicializar y valores sin destructor automático. | 1.36 |

## Conceptos clave

- **`swap`, `replace` y `take`** son la respuesta a «quiero sacar un valor de un campo pero solo tengo `&mut`» ([E0507](/errores/e0507/)): nunca dejan el sitio vacío.
- **`transmute`** es de lo más peligroso de Rust: casi siempre hay una alternativa segura (`from_le_bytes`, `as`, `From`).

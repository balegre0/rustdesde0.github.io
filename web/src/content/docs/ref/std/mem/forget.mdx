**Ruta:** `std::mem::forget`

## Sinopsis

```rust
pub const fn forget<T>(t: T)
```

## Qué hace

`forget(x)` toma la propiedad de `x` y **no ejecuta su `Drop`**: la memoria o el recurso que tuviera no se liberan nunca. Es seguro (no es comportamiento indefinido), porque Rust no garantiza que los destructores se ejecuten siempre: también se «olvidan» valores con ciclos de `Rc` o con `Box::leak`. Se usa sobre todo con código `unsafe` y FFI, cuando otro código pasa a ser el dueño. Para destruir un valor ya, usa `drop`.

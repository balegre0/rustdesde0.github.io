**Ruta:** `std::mem::{swap, replace, take}`

## Sinopsis

```rust
pub const fn swap<T>(x: &mut T, y: &mut T)

pub const fn replace<T>(dest: &mut T, src: T) -> T

pub fn take<T>(dest: &mut T) -> T
where
    T: Default,
```

## Qué hace

Las tres trabajan a través de préstamos exclusivos y nunca dejan un hueco, así que son seguras:

- `swap(&mut a, &mut b)`: intercambia los dos valores.
- `replace(&mut sitio, nuevo)`: pone `nuevo` y te devuelve lo que había.
- `take(&mut sitio)`: te devuelve lo que había y deja `T::default()` (necesita `Default`: texto vacío, `0`, `None`, vector vacío…).

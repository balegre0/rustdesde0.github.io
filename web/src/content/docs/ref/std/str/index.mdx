**Ruta:** `primitivo str (y el módulo std::str)`

## Para qué sirve

`str` es el tipo primitivo del **texto UTF-8**. Casi siempre lo verás detrás de una referencia, `&str`: un puntero al primer byte más una longitud. Los literales (`"hola"`) son `&'static str`: viven dentro del programa. Un `&str` también puede apuntar dentro de un `String`. El módulo `std::str` contiene funciones auxiliares (`from_utf8`) y los tipos de los iteradores (`Split`, `Chars`…).

## Conceptos clave

- **`&str` no es dueño**: no puede crecer; para modificar texto necesitas un `String`.
- **Los métodos que transforman** (`to_uppercase`, `replace`) crean un `String` nuevo; los que buscan o dividen devuelven trozos `&str` del original, sin copiar.

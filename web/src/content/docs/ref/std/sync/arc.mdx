**Ruta:** `std::sync::Arc`

## Sinopsis

```rust
pub struct Arc<T, A = Global>
where
    A: Allocator,
    T: ?Sized,
{ /* private fields */ }
```

## Qué hace

`Arc<T>` (*atomically reference counted*) funciona igual que `Rc<T>`, pero suma y resta su contador con **operaciones atómicas**, que son seguras aunque varios hilos lo hagan a la vez. Es `Send` y `Sync` si `T` es `Send + Sync`. Como `Rc`, solo da acceso compartido: para modificar, combínalo con `Mutex`, `RwLock` o atómicos.

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`new`](#new) | Crea el primer `Arc`. | 1.0 |
| [`clone`](#clone) | Otro dueño (suma 1, de forma atómica). | 1.0 |
| [`strong_count`](#strong_count) | Cuántos dueños hay en este momento (otro hilo puede cambiarlo justo después). | 1.15 |
| [`downgrade`](#downgrade) | Crea un `sync::Weak`. | 1.4 |
| [`try_unwrap`](#try_unwrap) | Recupera el valor si es el único dueño. | 1.4 |

### `new`

```rust
pub fn new(data: T) -> Arc<T>
```

Crea el primer `Arc`.

### `clone`

```rust
fn clone(&self) -> Arc<T, A>
```

Otro dueño (suma 1, de forma atómica).

### `strong_count`

```rust
pub fn strong_count(this: &Arc<T, A>) -> usize
```

Cuántos dueños hay en este momento (otro hilo puede cambiarlo justo después).

### `downgrade`

```rust
pub fn downgrade(this: &Arc<T, A>) -> Weak<T, A>
where
    A: AllocatorClone,
```

Crea un `sync::Weak`.

### `try_unwrap`

```rust
pub fn try_unwrap(this: Arc<T, A>) -> Result<T, Arc<T, A>>
```

Recupera el valor si es el único dueño.

## Rendimiento

Las operaciones atómicas cuestan algo más que las normales: en un solo hilo, `Rc` es más barato.

## Desde

Rust 1.0 (estable). Métodos de esta página añadidos después: `strong_count` (1.15), `downgrade` (1.4), `try_unwrap` (1.4).

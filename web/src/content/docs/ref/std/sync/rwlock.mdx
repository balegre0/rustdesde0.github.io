**Ruta:** `std::sync::RwLock`

## Sinopsis

```rust
pub struct RwLock<T: ?Sized> { /* private fields */ }
```

## Qué hace

Un `RwLock<T>` aplica entre hilos la misma regla que el borrow checker: **varios lectores** (`read()`, como `&T`) **o un escritor** (`write()`, como `&mut T`). Conviene cuando hay muchas más lecturas que escrituras.

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`new`](#new) | Crea el cerrojo con el valor dentro. | 1.0 |
| [`read`](#read) | Bloquea para leer (compartido). | 1.0 |
| [`write`](#write) | Bloquea para escribir (exclusivo). | 1.0 |
| [`try_write`](#try_write) | Intenta bloquear para escribir sin esperar. | 1.0 |
| [`into_inner`](#into_inner) | Consume el cerrojo y devuelve el valor. | 1.6 |

### `new`

```rust
pub const fn new(t: T) -> RwLock<T>
```

Crea el cerrojo con el valor dentro.

### `read`

```rust
pub fn read(&self) -> LockResult<RwLockReadGuard<'_, T>>
```

Bloquea para leer (compartido).

### `write`

```rust
pub fn write(&self) -> LockResult<RwLockWriteGuard<'_, T>>
```

Bloquea para escribir (exclusivo).

### `try_write`

```rust
pub fn try_write(&self) -> TryLockResult<RwLockWriteGuard<'_, T>>
```

Intenta bloquear para escribir sin esperar.

### `into_inner`

```rust
pub fn into_inner(self) -> LockResult<T>
where
    T: Sized,
```

Consume el cerrojo y devuelve el valor.

**Ruta:** `std::sync`

## Para qué sirve

Este módulo tiene las herramientas para **compartir datos entre hilos** de forma segura. El compilador impide las **carreras de datos** (dos hilos accediendo a la vez a lo mismo, al menos uno escribiendo) con los traits `Send` y `Sync`; estos tipos son la forma permitida de compartir.

| `LazyLock` | Un valor que se calcula la primera vez que se usa: ideal para `static`. | 1.80 |

## Conceptos clave

- **El patrón típico**: `Arc<Mutex<T>>`. `Arc` da varios dueños entre hilos; `Mutex` da acceso exclusivo para modificar.
- **Envenenamiento** (*poisoning*): si un hilo entra en pánico con un `Mutex` bloqueado, el cerrojo queda «envenenado» y los siguientes `lock()` devuelven `Err`. Por eso se escribe `lock().unwrap()`.
- **Interbloqueo** (*deadlock*): dos hilos que esperan cada uno el cerrojo del otro se quedan parados para siempre. Rust no lo impide: no es comportamiento indefinido. Bloquea siempre en el mismo orden.
- **En el navegador no hay hilos**, pero todos estos tipos funcionan en un solo hilo; los ejemplos de hilos se ejecutan en el Playground.

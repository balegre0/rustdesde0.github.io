**Ruta:** `std::hash`

## Para qué sirve

Un **hash** es un número que resume un valor: valores iguales dan siempre el mismo hash. `HashMap` y `HashSet` lo usan para saber dónde guardar cada clave. Un tipo puede ser clave si implementa `Hash` y `Eq`; casi siempre basta con `#[derive(Hash, PartialEq, Eq)]`.

## Conceptos clave

- **La regla de oro**: si `a == b`, entonces `hash(a) == hash(b)`. Si implementas `Hash` o `PartialEq` a mano, deben ser coherentes; si no, el `HashMap` no encontrará tus claves (no es comportamiento indefinido, pero es un error lógico).
- **El valor del hash cambia entre ejecuciones** (semilla aleatoria) y entre versiones de Rust: no lo guardes en archivos.

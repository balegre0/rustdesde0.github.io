**Ruta:** `std::hash::{Hash, Hasher, BuildHasher}`

## Sinopsis

```rust
pub trait Hash {
    fn hash<H: Hasher>(&self, estado: &mut H);
}
pub trait Hasher {
    fn finish(&self) -> u64;
    fn write(&mut self, bytes: &[u8]);
}
```

## Qué hace

`HashMap` y `HashSet` necesitan un número (el **hash**) para cada clave. El trabajo se reparte:

- **`Hash`** (lo implementa tu tipo, casi siempre con `#[derive(Hash)]`): dice **qué** datos se meten en la mezcla.
- **`Hasher`** (lo elige el mapa): hace la **mezcla**. El de `HashMap` por defecto es SipHash 1-3 con una clave aleatoria, resistente a ataques que buscan colisiones.

**La regla de oro:** si `a == b`, entonces `hash(a) == hash(b)`. Si implementas `Hash` a mano (por ejemplo, ignorando mayúsculas), `PartialEq` tiene que seguir el mismo criterio, o el mapa se comportará de forma incoherente (sin comportamiento indefinido, pero con resultados incorrectos).

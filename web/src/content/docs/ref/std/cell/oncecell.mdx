**Ruta:** `std::cell::OnceCell`

## Sinopsis

```rust
pub struct OnceCell<T> { /* private fields */ }
```

## Qué hace

`OnceCell<T>` empieza vacía y se puede rellenar **una vez**. Después, solo se lee, y por eso puede dar `&T` normales. `get_or_init` calcula el valor solo la primera vez que se pide. Para `static` y para varios hilos, usa `std::sync::OnceLock` (o `LazyLock`).

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`new`](#new) | Crea una celda vacía. | 1.70 |
| [`get`](#get) | `Some(&T)` si ya tiene valor. | 1.70 |
| [`set`](#set) | Intenta poner el valor; si ya tenía uno, devuelve `Err(valor)`. | 1.70 |
| [`get_or_init`](#get_or_init) | Devuelve el valor, calculándolo con la closure si todavía no existe. | 1.70 |

### `new`

```rust
pub const fn new() -> OnceCell<T>
```

Crea una celda vacía.

### `get`

```rust
pub fn get(&self) -> Option<&T>
```

`Some(&T)` si ya tiene valor.

### `set`

```rust
pub fn set(&self, value: T) -> Result<(), T>
```

Intenta poner el valor; si ya tenía uno, devuelve `Err(valor)`.

### `get_or_init`

```rust
pub fn get_or_init<F>(&self, f: F) -> &T
where
    F: FnOnce() -> T,
```

Devuelve el valor, calculándolo con la closure si todavía no existe.

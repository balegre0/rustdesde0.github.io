**Ruta:** `std::cell::Cell`

## Sinopsis

```rust
pub struct Cell<T>
where
    T: ?Sized,
{ /* private fields */ }
```

## Qué hace

`Cell<T>` guarda un valor que puedes cambiar aunque solo tengas `&Cell<T>`. No da referencias al interior: `get` copia el valor hacia fuera (requiere `T: Copy`) y `set` lo reemplaza. Ideal para contadores y banderas dentro de structs que se usan con `&self`.

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`new`](#new) | Crea la celda. | 1.0 |
| [`get`](#get) | Devuelve una copia del valor (`T: Copy`). | 1.0 |
| [`set`](#set) | Reemplaza el valor. | 1.0 |
| [`replace`](#replace) | Pone un valor y devuelve el anterior. | 1.17 |
| [`update`](#update) | Aplica una función al valor y guarda el resultado. | 1.88 |
| [`take`](#take) | Saca el valor dejando `T::default()`. | 1.17 |
| [`into_inner`](#into_inner) | Consume la celda y devuelve el valor. | 1.17 |

### `new`

```rust
pub const fn new(value: T) -> Cell<T>
```

Crea la celda.

### `get`

```rust
pub const fn get(&self) -> T
```

Devuelve una copia del valor (`T: Copy`).

### `set`

```rust
pub fn set(&self, val: T)
```

Reemplaza el valor.

### `replace`

```rust
pub const fn replace(&self, val: T) -> T
```

Pone un valor y devuelve el anterior.

### `update`

```rust
pub fn update(&self, f: impl FnOnce(T) -> T)
```

Aplica una función al valor y guarda el resultado.

### `take`

```rust
pub fn take(&self) -> T
where
    T: Default,
```

Saca el valor dejando `T::default()`.

### `into_inner`

```rust
pub const fn into_inner(self) -> T
```

Consume la celda y devuelve el valor.

## Rendimiento

Sin coste extra: `Cell<T>` ocupa lo mismo que `T` y sus operaciones son copias normales.

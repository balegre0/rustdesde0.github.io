**Ruta:** `std::collections::BTreeMap`

## Sinopsis

```rust
pub struct BTreeMap<K, V, A = Global>
where
    A: Allocator + Clone,
{ /* private fields */ }
```

## Qué hace

Un `BTreeMap` guarda los pares en un **árbol B**: nodos con varias claves ordenadas cada uno. Es algo más lento que `HashMap` para buscar, pero se recorre siempre en orden de clave y permite pedir rangos (`range`), el mínimo y el máximo.

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`insert`](#insert) | Inserta o reemplaza; devuelve el valor anterior. | 1.0 |
| [`get`](#get) | Busca una clave. | 1.0 |
| [`range`](#range) | Iterador de los pares cuyas claves caen en un rango. | 1.17 |
| [`first_key_value`](#first_key_value) | El par con la clave más pequeña. | 1.66 |
| [`last_key_value`](#last_key_value) | El par con la clave más grande. | 1.66 |
| [`entry`](#entry) | Igual que en `HashMap`: insertar o modificar en un paso. | 1.0 |
| [`remove`](#remove) | Quita una clave. | 1.0 |



**Salida:**

```text
Ana: 9
Eva: 5
Luis: 7
Some(("Ana", 9))
Some(("Luis", 7))
[("Eva", 5), ("Luis", 7)]
{"Ana": 9, "Eva": 6, "Luis": 7}
```

## Rendimiento

`insert`, `get` y `remove`: O(log n). Recorrer en orden: O(n).

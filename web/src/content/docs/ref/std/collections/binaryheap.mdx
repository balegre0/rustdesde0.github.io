## Sinopsis

```rust
pub struct BinaryHeap<T, A = Global>
where
    A: Allocator,
{ /* private fields */ }
```

## Qué hace

Un `BinaryHeap` es un **montículo binario** guardado en un `Vec`: el elemento mayor (según `Ord`) siempre está arriba. Para que salga primero el menor, envuelve los valores en `std::cmp::Reverse`.

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`push`](#push) | Añade un elemento. | 1.0 |
| [`pop`](#pop) | Saca el mayor. | 1.0 |
| [`peek`](#peek) | Mira el mayor sin sacarlo. | 1.0 |
| [`len`](#len) | Número de elementos. | 1.0 |
| [`into_sorted_vec`](#into_sorted_vec) | Consume el montículo y devuelve un `Vec` ordenado de menor a mayor. | 1.5 |

### `push`

```rust
pub fn push(&mut self, item: T)
```

Añade un elemento.

### `pop`

```rust
pub fn pop(&mut self) -> Option<T>
```

Saca el mayor.

### `peek`

```rust
pub fn peek(&self) -> Option<&T>
```

Mira el mayor sin sacarlo.

### `len`

```rust
pub fn len(&self) -> usize
```

Número de elementos.

### `into_sorted_vec`

```rust
pub fn into_sorted_vec(self) -> Vec<T, A>
```

Consume el montículo y devuelve un `Vec` ordenado de menor a mayor.

## Rendimiento

`push` y `pop`: O(log n). `peek`: O(1).

**Ruta:** `std::rc`

## Para qué sirve

A veces un valor necesita **varios dueños** (por ejemplo, un nodo al que apuntan varios otros). `Rc<T>` (*reference counted*) lleva la cuenta de cuántos dueños hay; el valor se destruye cuando el último desaparece. `Weak<T>` es una referencia que **no cuenta** como dueño, para romper ciclos.

## Conceptos clave

- **Solo lectura**: `Rc<T>` da acceso compartido (`&T`). Para modificar, combínalo con `Cell` o `RefCell`: `Rc<RefCell<T>>`.
- **Solo un hilo**: el contador de `Rc` no es atómico, así que `Rc` no es `Send` ni `Sync`. Entre hilos se usa `Arc`.
- **Ciclos = fugas**: si dos `Rc` se apuntan entre sí, sus contadores nunca llegan a 0 y la memoria no se libera. No es comportamiento indefinido, pero es una fuga. Usa `Weak` en uno de los sentidos.

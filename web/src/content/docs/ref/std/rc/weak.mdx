**Ruta:** `std::rc::Weak`

## Sinopsis

```rust
pub struct Weak<T, A = Global>
where
    A: Allocator,
    T: ?Sized,
{ /* private fields */ }
```

## Qué hace

Un `Weak<T>` apunta al valor de un `Rc` pero no cuenta como dueño. Como el valor puede haberse destruido ya, para usarlo hay que llamar a `upgrade()`, que devuelve `Some(Rc)` si sigue vivo o `None` si no.

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`new`](#new) | Un `Weak` que no apunta a nada (`upgrade` siempre da `None`). | 1.10 |
| [`upgrade`](#upgrade) | Intenta obtener un `Rc`: `Some` si el valor sigue vivo. | 1.4 |
| [`strong_count`](#strong_count) | Cuántos dueños fuertes tiene el valor (0 si ya se destruyó). | 1.41 |

### `new`

```rust
pub const fn new() -> Weak<T>
```

Un `Weak` que no apunta a nada (`upgrade` siempre da `None`).

### `upgrade`

```rust
pub fn upgrade(&self) -> Option<Rc<T, A>>
where
    A: AllocatorClone,
```

Intenta obtener un `Rc`: `Some` si el valor sigue vivo.

### `strong_count`

```rust
pub fn strong_count(&self) -> usize
```

Cuántos dueños fuertes tiene el valor (0 si ya se destruyó).

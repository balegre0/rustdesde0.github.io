**Ruta:** `std::result`

## Para qué sirve

Las operaciones que pueden fallar de forma **esperable** (leer un archivo, convertir texto en número, conectarse a algo) devuelven `Result<T, E>`: `Ok(valor)` si todo fue bien, o `Err(error)` con la explicación. Igual que con `Option`, el compilador no te deja usar el valor sin mirar antes si hubo error. Los fallos que indican un **error del programa** (un índice imposible) se tratan con pánico, no con `Result`.

## Conceptos clave

- **El operador `?`**: dentro de una función que devuelve `Result`, `valor?` saca el `Ok` o **devuelve el `Err` al que llama** (convirtiéndolo con `From` si hace falta). Es la forma normal de propagar errores.
- **`#[must_use]`**: si ignoras un `Result`, el compilador te avisa con un *warning*.
- **Recoger**: un iterador de `Result<T, E>` se puede recoger en `Result<Vec<T>, E>`; se detiene en el primer error.

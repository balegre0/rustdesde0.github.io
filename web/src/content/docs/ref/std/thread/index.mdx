**Ruta:** `std::thread`

## Para qué sirve

Un **hilo** (*thread*) es una línea de ejecución que corre a la vez que las demás. `thread::spawn` crea uno nuevo; `join` espera a que termine. Rust impide las carreras de datos entre hilos **al compilar**: lo que mandas a otro hilo debe ser `Send`, y lo que compartes, `Sync`.

**En el navegador no hay hilos**: `thread::spawn` entra en pánico (ver abajo). Los ejemplos con hilos se ejecutan en el Playground.

## Contenido de un vistazo

| Nombre | Resumen | Desde |
|---|---|---|
| [`spawn`](/ref/std/thread/spawn/) | Crea un hilo que puede vivir más que quien lo crea. | 1.0 |
| [`scope`](/ref/std/thread/scope/) | Hilos que terminan antes de salir del bloque: pueden tomar prestado. | 1.63 |
| `JoinHandle` | Esperar a un hilo y recoger su resultado. | 1.0 |
| `sleep` | Duerme el hilo actual al menos ese tiempo. | 1.4 |
| `current` | El hilo actual (nombre, id). | 1.0 |
| `available_parallelism` | Cuántos hilos pueden correr de verdad a la vez. | 1.59 |
| `thread_local!` | Una variable distinta para cada hilo. | 1.0 |

## Conceptos clave

- **`move`**: la closure de `spawn` debe ser `'static`, así que casi siempre lleva `move` para llevarse sus datos ([E0373](/errores/e0373/)).
- **Pánicos**: si un hilo entra en pánico, solo muere ese hilo; `join` devuelve `Err`.
- **Al terminar `main`**, el programa acaba aunque queden hilos sin `join`.

**Ruta:** `std::thread::spawn`

## Sinopsis

```rust
pub fn spawn<F, T>(f: F) -> JoinHandle<T>
where
    F: FnOnce() -> T + Send + 'static,
    T: Send + 'static,
```

## Qué hace

`spawn` lanza la closure en un hilo nuevo y vuelve enseguida con un `JoinHandle<T>`. `handle.join()` espera a que termine y devuelve `Ok(resultado)`, o `Err` si el hilo entró en pánico. Los límites `F: Send + 'static` significan: lo que la closure lleva dentro se puede mandar a otro hilo y no toma prestado nada que pueda desaparecer.

## Pánicos

`spawn` entra en pánico si el sistema no puede crear el hilo (en el navegador siempre: ver el ejemplo de [std::thread](/ref/std/thread/)). `thread::Builder::spawn` devuelve el error en lugar de entrar en pánico.

**Ruta:** `std::ops::{Add, Sub, Mul, Neg, AddAssign, Index…}`

## Sinopsis

```rust
pub trait Add<Rhs = Self> {
    type Output;

    // Required method
    fn add(self, rhs: Rhs) -> Self::Output;
}

pub trait AddAssign<Rhs = Self> {
    // Required method
    fn add_assign(&mut self, rhs: Rhs);
}

pub trait Neg {
    type Output;

    // Required method
    fn neg(self) -> Self::Output;
}

pub trait Index<Idx>
where
    Idx: ?Sized,
{
    type Output: ?Sized;

    // Required method
    fn index(&self, index: Idx) -> &Self::Output;
}
```

## Qué hace

| Operador | Trait | Operador | Trait |
|---|---|---|---|
| `a + b` | `Add` | `a += b` | `AddAssign` |
| `a - b` | `Sub` | `a -= b` | `SubAssign` |
| `a * b` | `Mul` | `a *= b` | `MulAssign` |
| `a / b` | `Div` | `a % b` | `Rem` |
| `-a` | `Neg` | `!a` | `Not` |
| `a & b`, `a \| b`, `a ^ b` | `BitAnd`, `BitOr`, `BitXor` | `a << b`, `a >> b` | `Shl`, `Shr` |
| `v[i]` | `Index` | `v[i] = x` | `IndexMut` |

Los binarios tienen un parámetro `Rhs` (el tipo de la derecha, por defecto `Self`) y un tipo asociado `Output` (el resultado). Así puedes definir, por ejemplo, `Vector * f64`.

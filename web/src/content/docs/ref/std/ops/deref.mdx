**Ruta:** `std::ops::Deref, std::ops::DerefMut`

## Sinopsis

```rust
pub trait Deref {
    type Target: ?Sized;

    // Required method
    fn deref(&self) -> &Self::Target;
}

pub trait DerefMut: Deref {
    // Required method
    fn deref_mut(&mut self) -> &mut Self::Target;
}
```

## Qué hace

`Deref` dice a qué apunta un tipo «puntero»: `*x` llama a `deref`. Además, el compilador aplica la **coerción por `Deref`**: si una función pide `&str` y le pasas `&String`, convierte `&String` → `&str` sola (`String: Deref<Target = str>`). Igual con `Box<T>` → `&T` y `Vec<T>` → `&[T]`. Y al llamar a un método, busca también en el `Target`. Impleméntalo solo en tipos que se comportan como punteros o envoltorios.

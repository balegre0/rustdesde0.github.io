## Sinopsis

```rust
pub trait Drop {
    // ... y 2 métodos provistos (con implementación por defecto)
}

pub fn drop<T>(_x: T)
```

## Qué hace

Cuando un valor sale de su ámbito, Rust lo **destruye**: llama a su `Drop::drop` (si lo tiene) y después destruye sus campos. Las variables se destruyen en **orden inverso** al que se crearon; los campos de un struct y los elementos de un `Vec`, en orden. Así funcionan `String`, `Vec`, `File` o `MutexGuard`: liberan su memoria, cierran o desbloquean solos (RAII).

No puedes llamar a `valor.drop()` tú mismo ([E0040](/errores/e0040/)): usa la función `drop(valor)`, que se lleva la propiedad y lo destruye en ese momento.

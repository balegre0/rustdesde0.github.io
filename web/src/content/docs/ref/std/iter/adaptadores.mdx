## Qué hace

Hay dos clases de métodos:

- **Adaptadores**: devuelven **otro iterador** (`map`, `filter`, `zip`…). Son perezosos.
- **Consumidores**: recorren el iterador y devuelven un resultado (`sum`, `count`, `collect`, `fold`…).

Muchos reciben una closure. Fíjate en el tipo que recibe: con `v.iter()` los elementos son `&T`, y en `filter` llegan como `&&T` (por eso a veces se escribe `**x` o `|&&x|`).

### `map`

```rust
fn map<B, F>(self, f: F) -> Map<Self, F>
where
    Self: Sized,
    F: FnMut(Self::Item) -> B,
```

**Adaptador.** Transforma cada elemento con la closure.

### `filter`

```rust
fn filter<P>(self, predicate: P) -> Filter<Self, P>
where
    Self: Sized,
    P: FnMut(&Self::Item) -> bool,
```

**Adaptador.** Deja pasar solo los elementos para los que la closure devuelve `true`.

### `filter_map`

```rust
fn filter_map<B, F>(self, f: F) -> FilterMap<Self, F>
where
    Self: Sized,
    F: FnMut(Self::Item) -> Option<B>,
```

**Adaptador.** Filtra y transforma a la vez: se queda con los `Some` y desecha los `None`.

### `enumerate`

```rust
fn enumerate(self) -> Enumerate<Self>
where
    Self: Sized,
```

**Adaptador.** Empareja cada elemento con su posición: `(0, a), (1, b)…`.

### `zip`

```rust
fn zip<U>(self, other: U) -> Zip<Self, <U as IntoIterator>::IntoIter>
where
    Self: Sized,
    U: IntoIterator,
```

**Adaptador.** Recorre dos iteradores a la vez, en parejas. Termina con el más corto.

### `chain`

```rust
fn chain<U>(self, other: U) -> Chain<Self, <U as IntoIterator>::IntoIter>
where
    Self: Sized,
    U: IntoIterator<Item = Self::Item>,
```

**Adaptador.** Pone un iterador detrás de otro.

### `take`

```rust
fn take(self, n: usize) -> Take<Self>
where
    Self: Sized,
```

**Adaptador.** Se queda con los `n` primeros. Sirve para cortar iteradores infinitos.

### `skip`

```rust
fn skip(self, n: usize) -> Skip<Self>
where
    Self: Sized,
```

**Adaptador.** Se salta los `n` primeros.

### `take_while`

```rust
fn take_while<P>(self, predicate: P) -> TakeWhile<Self, P>
where
    Self: Sized,
    P: FnMut(&Self::Item) -> bool,
```

**Adaptador.** Da elementos mientras se cumpla la condición; para en el primero que no.

### `step_by`

```rust
fn step_by(self, step: usize) -> StepBy<Self>
where
    Self: Sized,
```

**Adaptador.** Da uno de cada `step` elementos.

### `rev`

```rust
fn rev(self) -> Rev<Self>
where
    Self: Sized + DoubleEndedIterator,
```

**Adaptador.** Recorre al revés (necesita `DoubleEndedIterator`).

### `flat_map`

```rust
fn flat_map<U, F>(self, f: F) -> FlatMap<Self, U, F>
where
    Self: Sized,
    U: IntoIterator,
    F: FnMut(Self::Item) -> U,
```

**Adaptador.** Cada elemento produce un iterador, y se recorren todos seguidos.

### `peekable`

```rust
fn peekable(self) -> Peekable<Self>
where
    Self: Sized,
```

**Adaptador.** Permite mirar el siguiente elemento (`peek`) sin sacarlo.

### `copied`

```rust
fn copied<'a, T>(self) -> Copied<Self>
where
    T: Copy + 'a,
    Self: Sized + Iterator<Item = &'a T>,
```

**Adaptador.** Pasa de `&T` a `T` copiando (para tipos `Copy`).

### `cloned`

```rust
fn cloned<'a, T>(self) -> Cloned<Self>
where
    T: Clone + 'a,
    Self: Sized + Iterator<Item = &'a T>,
```

**Adaptador.** Pasa de `&T` a `T` clonando.

### `collect`

```rust
fn collect<B>(self) -> B
where
    B: FromIterator<Self::Item>,
    Self: Sized,
```

**Consumidor.** Construye una colección (`Vec`, `String`, `HashMap`…) con los elementos. Dile el tipo: `let v: Vec<_> = ...` o `collect::<Vec<_>>()`.

### `sum`

```rust
fn sum<S>(self) -> S
where
    Self: Sized,
    S: Sum<Self::Item>,
```

**Consumidor.** Suma los elementos. Necesita saber el tipo del resultado.

### `count`

```rust
fn count(self) -> usize
where
    Self: Sized,
```

**Consumidor.** Cuenta los elementos.

### `fold`

```rust
fn fold<B, F>(self, init: B, f: F) -> B
where
    Self: Sized,
    F: FnMut(B, Self::Item) -> B,
```

**Consumidor.** Acumula: empieza con un valor inicial y lo combina con cada elemento.

### `find`

```rust
fn find<P>(&mut self, predicate: P) -> Option<Self::Item>
where
    Self: Sized,
    P: FnMut(&Self::Item) -> bool,
```

**Consumidor.** Primer elemento que cumple la condición (`Option`).

### `position`

```rust
fn position<P>(&mut self, predicate: P) -> Option<usize>
where
    Self: Sized,
    P: FnMut(Self::Item) -> bool,
```

**Consumidor.** Posición del primer elemento que cumple la condición.

### `any`

```rust
fn any<F>(&mut self, f: F) -> bool
where
    Self: Sized,
    F: FnMut(Self::Item) -> bool,
```

**Consumidor.** ¿Alguno cumple la condición? Para en cuanto encuentra uno.

### `all`

```rust
fn all<F>(&mut self, f: F) -> bool
where
    Self: Sized,
    F: FnMut(Self::Item) -> bool,
```

**Consumidor.** ¿Todos la cumplen? Para en cuanto uno no.

### `min`

```rust
fn min(self) -> Option<Self::Item>
where
    Self: Sized,
    Self::Item: Ord,
```

**Consumidor.** El menor (`Option`; necesita `Ord`).

### `max_by_key`

```rust
fn max_by_key<B, F>(self, f: F) -> Option<Self::Item>
where
    B: Ord,
    Self: Sized,
    F: FnMut(&Self::Item) -> B,
```

**Consumidor.** El mayor según una clave calculada.

### `partition`

```rust
fn partition<B, F>(self, f: F) -> (B, B)
where
    Self: Sized,
    B: Default + Extend<Self::Item>,
    F: FnMut(&Self::Item) -> bool,
```

**Consumidor.** Reparte los elementos en dos colecciones según la condición.

### `nth`

```rust
fn nth(&mut self, n: usize) -> Option<Self::Item>
```

**Consumidor.** El elemento `n` (empezando en 0), consumiendo los anteriores.

### `last`

```rust
fn last(self) -> Option<Self::Item>
where
    Self: Sized,
```

**Consumidor.** El último elemento.

## Rendimiento

Las cadenas de adaptadores no crean colecciones intermedias: cada elemento pasa por toda la cadena antes de pedir el siguiente. `collect` reserva memoria de una vez si `size_hint` es exacto.

**Ruta:** `std::iter`

## Para qué sirve

Un **iterador** es cualquier cosa que puede darte valores **de uno en uno**: los elementos de un `Vec`, las letras de un texto, los números de un rango, las líneas de un archivo… Todos implementan el mismo trait, `Iterator`, y por eso comparten decenas de métodos para transformarlos, filtrarlos y combinarlos. El bucle `for` funciona con cualquier iterador.

## Conceptos clave

- **Perezosos** (*lazy*): un adaptador como `map` no hace nada hasta que alguien pide valores (un `for`, `collect`, `sum`…). El compilador avisa si creas uno y no lo usas.
- **Sin coste**: una cadena de adaptadores se compila a un bucle tan rápido como el escrito a mano.
- **Tres formas de recorrer un `Vec`**: `v.iter()` presta (`&T`), `v.iter_mut()` presta en exclusiva (`&mut T`) y `v.into_iter()` (o `for x in v`) **mueve** los elementos y consume el `Vec`.

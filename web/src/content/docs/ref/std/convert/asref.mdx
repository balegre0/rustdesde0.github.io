**Ruta:** `std::convert::AsRef, std::convert::AsMut` · está en el **preludio** (no necesita `use`)

## Sinopsis

```rust
pub trait AsRef<T>
where
    T: ?Sized,
{
    // Required method
    fn as_ref(&self) -> &T;
}

pub trait AsMut<T>
where
    T: ?Sized,
{
    // Required method
    fn as_mut(&mut self) -> &mut T;
}
```

## Qué hace

`AsRef<U>` da un `&U` a partir de `&self` sin copiar nada. Sirve para escribir funciones flexibles: `fn f<S: AsRef<str>>(s: S)` acepta `&str`, `String`, `&String`… y `fs::read_to_string` usa `AsRef<Path>` para aceptar textos y rutas. `AsMut` es lo mismo con préstamos exclusivos.

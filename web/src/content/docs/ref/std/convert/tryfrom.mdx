**Ruta:** `std::convert::TryFrom, std::convert::TryInto` · está en el **preludio** (no necesita `use`)

## Sinopsis

```rust
pub trait TryFrom<T>: Sized {
    type Error;

    // Required method
    fn try_from(value: T) -> Result<Self, Self::Error>;
}

pub trait TryInto<T>: Sized {
    type Error;

    // Required method
    fn try_into(self) -> Result<T, Self::Error>;
}
```

## Qué hace

`TryFrom<T> for U` es como `From`, pero devuelve `Result<U, Self::Error>`. La biblioteca la implementa entre todos los enteros: convertir `300i32` en `u8` da `Err(TryFromIntError)` en lugar de perder bits en silencio como `as`. Están en el preludio desde la edición 2021.

## Ejemplo

**Salida:**

```text
Fahrenheit(212.0) Fahrenheit(32.0) 180
hola 7 [97, 98, 99]

7%
Err("130 no es un porcentaje")
Err(TryFromIntError(PosOverflow))
Ok(200)
```

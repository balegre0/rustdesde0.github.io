**Ruta:** `std::convert::From, std::convert::Into` · está en el **preludio** (no necesita `use`)

## Sinopsis

```rust
pub trait From<T>: Sized {
    // Required method
    fn from(value: T) -> Self;
}

pub trait Into<T>: Sized {
    // Required method
    fn into(self) -> T;
}
```

## Qué hace

`From<T> for U` dice cómo crear un `U` a partir de un `T`, siempre con éxito y sin pérdida. Se usa como `U::from(t)` o, si el compilador sabe el tipo de destino, `t.into()`. La biblioteca estándar trae muchas: `String::from(&str)`, `i64::from(u8)`, `Vec::from([1, 2])`, `Box::from(x)`…

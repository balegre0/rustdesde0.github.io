**Ruta:** `std::time`

## Para qué sirve

Tres tipos para el tiempo: `Duration` es una **cantidad** (1,5 segundos); `Instant` es un **momento** de un reloj que solo avanza, para medir cuánto tarda algo; `SystemTime` es la **hora del sistema**, que el usuario o la red pueden cambiar (incluso hacia atrás).

## Contenido de un vistazo

| Nombre | Resumen | Desde |
|---|---|---|
| `Duration` | Una cantidad de tiempo, con precisión de nanosegundos. | 1.3 |
| `Instant` | Un instante de un reloj monótono, para medir. | 1.8 |
| `SystemTime` | La hora del sistema. | 1.8 |
| `UNIX_EPOCH` | El 1 de enero de 1970 a las 00:00 UTC. | 1.8 |

**Ficha detallada:** [Instant y Duration](/ref/std/time/instant-y-duration/)

## Conceptos clave

- **Para medir, `Instant`**: `let t = Instant::now(); ...; t.elapsed()`.
- **Las medidas varían** en cada ejecución: no se pueden copiar en la documentación. El ejemplo imprime comparaciones en lugar de los tiempos.
- **Fechas y zonas horarias** no están en `std`: hacen falta crates externos.

**Ruta:** `std::error`

## Para qué sirve

El trait `Error` es lo que tienen en común todos los errores: se pueden mostrar a una persona (`Display`), a quien programa (`Debug`) y pueden tener una **causa** (`source`). Implementarlo en tus tipos de error permite mezclarlos con los de la biblioteca y usar `Box<dyn Error>`.

**Ficha detallada:** [El trait Error](/ref/std/error/error/)

## Conceptos clave

- **Patrón habitual**: un `enum` con una variante por tipo de fallo, `impl Display`, `impl Error` y un `impl From<OtroError>` por cada error que quieras convertir con `?`.
- **`Box<dyn Error>`**: como `?` usa `From`, y existe `From<E> for Box<dyn Error>` para todo `E: Error`, una función que devuelve `Result<T, Box<dyn Error>>` puede usar `?` con cualquier error.
- **`fn main() -> Result<(), Box<dyn Error>>`**: si devuelve `Err`, el programa muestra el error y sale con código 1.

## Métodos principales

```rust
fn source(&self) -> Option<&(dyn Error + 'static)>
```

Devuelve la causa del error, si la hay (por defecto, `None`). Recorriendo `source()` una y otra vez se obtiene la cadena completa de causas.

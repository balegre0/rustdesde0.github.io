**Ruta:** `std::error::Error` (también `core::error::Error`)

## Sinopsis

```rust
pub trait Error: Debug + Display {
    fn source(&self) -> Option<&(dyn Error + 'static)> { None }
}
```

## Qué hace

Un tipo de error implementa `Error` para que cualquier código pueda tratarlo de forma uniforme:

- **`Display`**: el mensaje para personas («configuración mal escrita en la línea 3»).
- **`Debug`**: la representación para programadores (normalmente derivada).
- **`source()`**: el error que lo **causó**, si lo hay. Así se forman cadenas de causas.

Cualquier `E: Error` se convierte con `?` en un `Box<dyn Error>`, gracias a una implementación de `From` de la biblioteca estándar. Por eso `fn main() -> Result<(), Box<dyn Error>>` acepta errores de cualquier tipo.

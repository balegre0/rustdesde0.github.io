```rust
pub trait BufRead: Read {

    // ... y 6 métodos provistos (con implementación por defecto)
```

## Qué hace

`BufRead` añade a un lector un búfer interno y, con él, operaciones que necesitan mirar por delante: leer hasta el fin de línea o hasta un byte. Envuelve cualquier `Read` en un `BufReader::new(...)` para tenerlo.

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`read_line`](#read_line) | Lee hasta `\n` (incluido) y lo añade al `String`. | 1.0 |
| [`lines`](#lines) | Iterador de líneas, cada una un `io::Result<String>` sin el salto de línea. | 1.0 |
| [`read_until`](#read_until) | Lee hasta un byte dado y lo añade a un `Vec<u8>`. | 1.0 |
| [`split`](#split) | Iterador de trozos separados por un byte. | 1.0 |

### `read_line`

```rust
fn read_line(&mut self, buf: &mut String) -> Result<usize, Error>
```

Lee hasta `\n` (incluido) y lo añade al `String`.

### `lines`

```rust
fn lines(self) -> Lines<Self>
where
    Self: Sized,
```

Iterador de líneas, cada una un `io::Result<String>` sin el salto de línea.

### `read_until`

```rust
fn read_until(&mut self, byte: u8, buf: &mut Vec<u8>) -> Result<usize, Error>
```

Lee hasta un byte dado y lo añade a un `Vec<u8>`.

### `split`

```rust
fn split(self, byte: u8) -> Split<Self>
where
    Self: Sized,
```

Iterador de trozos separados por un byte.

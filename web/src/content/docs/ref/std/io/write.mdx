## Sinopsis

```rust
pub trait Write {
    // Required methods
    fn write(&mut self, buf: &[u8]) -> Result<usize, Error>;
    fn flush(&mut self) -> Result<(), Error>;

    // ... y 6 métodos provistos (con implementación por defecto)
}
```

## Qué hace

`Write` tiene dos métodos obligatorios: `write` (escribe parte de un búfer) y `flush` (vacía lo pendiente). Lo implementan `File`, `Stdout`, `Stderr`, `Vec<u8>`, `TcpStream`… Con `write!` y `writeln!` escribes texto formateado en cualquiera de ellos.

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`write`](#write) | Escribe **parte** del búfer y devuelve cuántos bytes escribió. | 1.0 |
| [`write_all`](#write_all) | Escribe el búfer entero (repite `write` hasta terminar). | 1.0 |
| [`flush`](#flush) | Asegura que todo lo escrito llega a su destino. | 1.0 |
| [`write_fmt`](#write_fmt) | Lo que usan por dentro `write!` y `writeln!`. | 1.0 |

### `write`

```rust
fn write(&mut self, buf: &[u8]) -> Result<usize, Error>
```

Escribe **parte** del búfer y devuelve cuántos bytes escribió.

### `write_all`

```rust
fn write_all(&mut self, buf: &[u8]) -> Result<(), Error>
```

Escribe el búfer entero (repite `write` hasta terminar).

### `flush`

```rust
fn flush(&mut self) -> Result<(), Error>
```

Asegura que todo lo escrito llega a su destino.

### `write_fmt`

```rust
fn write_fmt(&mut self, args: Arguments<'_>) -> Result<(), Error>
```

Lo que usan por dentro `write!` y `writeln!`.

**Ruta:** `std::unreachable`

## Sinopsis

```rust
macro_rules! unreachable {
    ($($arg:tt)*) => { ... };
}
```

## Qué hace

Úsalo en ramas que sabes imposibles pero que el compilador no puede descartar (por ejemplo, el `_` de un `match` sobre `x % 2`). Si tu razonamiento falla, el programa entra en pánico con un mensaje claro en lugar de seguir con datos imposibles. No confundir con `std::hint::unreachable_unchecked`, que es `unsafe` y, si se alcanza, es comportamiento indefinido.

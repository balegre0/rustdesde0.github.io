**Ruta:** `std::matches`

## Sinopsis

```rust
macro_rules! matches {
    ($expression:expr, $pattern:pat $(if $guard:expr)? $(,)?) => { ... };
}
```

## Qué hace

`matches!(valor, patrón)` es un atajo de `match valor { patrón => true, _ => false }`. Admite alternativas con `|`, rangos y una guarda `if`. Muy útil dentro de `filter` y `assert!`.

**Ruta:** `std::concat`, `std::stringify`

## Sinopsis

```rust
concat!("a", 1, true, 'c')   // "a1truec": &'static str
stringify!(1 + 2)            // "1 + 2": &'static str
```

## Qué hace

- **`concat!`** junta **literales** (textos, números, booleanos, caracteres) en un único `&'static str`, al compilar. No acepta variables: si necesitas valores calculados, usa `format!`.
- **`stringify!`** devuelve el texto del código que le pasas, **sin evaluarlo**. Se usa sobre todo dentro de otras macros, para mostrar la expresión junto a su valor (como hacen `assert!` y `dbg!`). Normaliza los espacios.

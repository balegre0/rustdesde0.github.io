**Ruta:** `std::ptr::addr_of`, `std::ptr::addr_of_mut`; sintaxis `&raw const` y `&raw mut` (1.82)

## Sinopsis

```rust
&raw const lugar     // *const T
&raw mut lugar       // *mut T
ptr::addr_of!(lugar)       // lo mismo que &raw const
ptr::addr_of_mut!(lugar)   // lo mismo que &raw mut
```

## Qué hace

`&lugar as *const T` crea **primero una referencia** y luego la convierte. Pero crear una referencia exige que el lugar esté alineado y contenga un valor válido. En algunos casos eso no se cumple:

- campos de un struct `#[repr(packed)]` (pueden estar desalineados);
- memoria todavía sin inicializar (`MaybeUninit`);
- registros de hardware, que no deben tratarse como memoria normal.

`&raw const` y `&raw mut` crean el puntero **directamente**, sin referencia intermedia, y no son `unsafe` (lo `unsafe` es usar el puntero después).

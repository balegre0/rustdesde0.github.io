**Ruta:** `std::write, std::writeln`

## Sinopsis

```rust
macro_rules! write {
    ($dst:expr, $($arg:tt)*) => { ... };
    ($($arg:tt)*) => { ... };
}

macro_rules! writeln {
    ($dst:expr $(,)?) => { ... };
    ($dst:expr, $($arg:tt)*) => { ... };
    ($($arg:tt)*) => { ... };
}
```

## Qué hace

`write!(destino, "...", args)` llama a `destino.write_fmt(...)`, así que sirve con cualquier tipo que tenga ese método: los que implementan `std::fmt::Write` (`String`) o `std::io::Write` (`File`, `Stdout`, `Vec<u8>`…). Devuelve un `Result`: usa `?`. Importa el trait que toque; si necesitas los dos en el mismo archivo, renómbralos al importarlos (`use std::fmt::Write as FmtWrite;`).

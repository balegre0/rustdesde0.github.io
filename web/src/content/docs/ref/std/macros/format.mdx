**Ruta:** `std::format`

## Sinopsis

```rust
macro_rules! format {
    ($($arg:tt)*) => { ... };
}
```

## Qué hace

`format!` construye un `String` nuevo con la [sintaxis de formato](/ref/std/fmt/sintaxis/). Si solo vas a pasarlo a otra macro, `format_args!` hace lo mismo sin reservar memoria.

## Ejemplo

<Ejecutar ej="ref-std/macros-format" />

**Salida:**

```text
3 al cuadrado es 9
 1 |  10
 2 |  20
 3 |  30
a-b
0xff 0b11111111
```

**Ruta:** `std::vec`

## Sinopsis

```rust
macro_rules! vec {
    () => { ... };
    ($elem:expr; $n:expr) => { ... };
    ($($x:expr),+ $(,)?) => { ... };
}
```

## Qué hace

Tres formas: `vec![a, b, c]` con elementos; `vec![valor; n]` con `n` copias (el valor debe ser `Clone`); `vec![]` vacío.

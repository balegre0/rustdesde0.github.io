**Ruta:** `std::compile_error`

## Sinopsis

```rust
compile_error!("mensaje");
```

## Qué hace

Si el compilador llega a procesar la macro, la compilación **falla** con tu mensaje. Por eso casi siempre va detrás de un `#[cfg(...)]` (para rechazar plataformas o combinaciones de features que no soportas) o dentro de una `macro_rules!` (para dar un error claro cuando la usan mal).

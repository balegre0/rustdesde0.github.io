**Ruta:** `std (macros exportadas en la raíz)`

## Para qué sirve

Las macros se reconocen por el `!`. A diferencia de las funciones, pueden recibir un número variable de argumentos y generar código al compilar (por ejemplo, comprobar el texto de formato de `println!`). Todas estas están disponibles en cualquier sitio sin `use`.

| [`panic!`](/ref/std/macros/panic/) | Detiene el hilo actual con un mensaje. | 1.0 |

| [`todo!`](/ref/std/macros/todo/) | Marca código sin terminar. | 1.40 |

## Conceptos clave

- **Lo que generan se puede ver**: `cargo expand` (una herramienta externa) muestra el código que produce cada macro.
- **Tus propias macros** se escriben con `macro_rules!` o como macros procedurales.

**Ruta:** `std::panic`

## Sinopsis

```rust
macro_rules! panic {
    ($($arg:tt)*) => { ... };
}
```

## Qué hace

`panic!` **entra en pánico**: muestra el mensaje y la ubicación, deshace la pila del hilo ejecutando los destructores (*unwinding*) y termina el hilo. Si es el hilo principal, termina el programa con un código de error. Úsalo para situaciones que **no deberían pasar nunca** si el programa es correcto; para errores esperables (un archivo que no existe), devuelve `Result`.

## Ejemplo

<Ejecutar ej="ref-std/macros-panic" />

**Salida:**

```text
5
```

**Salida de error** (*stderr*):

```text
thread 'main' (1) panicked at macros-panic.rs:3:9:
división por cero: 1 / 0
```

**Ruta:** `std::env`, `std::option_env`

## Sinopsis

```rust
env!("NOMBRE")                 // &'static str; error de compilación si no existe
env!("NOMBRE", "mensaje si no existe")
option_env!("NOMBRE")          // Option<&'static str>
```

## Qué hace

Leen variables de entorno **en el momento de compilar**, no al ejecutar: el valor queda grabado en el ejecutable. Para leer el entorno **al ejecutar**, se usa [`std::env::var`](/ref/std/env/args-y-var/).

Cargo define muchas variables útiles durante la compilación:

```rust
const VERSION: &str = env!("CARGO_PKG_VERSION");
const NOMBRE: &str = env!("CARGO_PKG_NAME");
```

Y `build.rs` puede añadir las suyas con `cargo::rustc-env=CLAVE=VALOR`.

**Ruta:** `std::todo`

## Sinopsis

```rust
macro_rules! todo {
    () => { ... };
    ($($arg:tt)+) => { ... };
}
```

## Qué hace

`todo!()` tiene el tipo `!` («nunca devuelve»), que encaja con cualquier tipo de retorno. Así puedes dejar funciones a medias y el programa compila. Si llega a ejecutarse, entra en pánico con «not yet implemented». `unimplemented!` es parecido, pero da a entender que no se va a implementar.

## Ejemplo

<Ejecutar ej="ref-std/macros-todo" />

**Salida:**

```text
9
```

**Salida de error** (*stderr*):

```text
thread 'main' (1) panicked at macros-todo.rs:14:9:
not yet implemented: falta calcular el perímetro
```

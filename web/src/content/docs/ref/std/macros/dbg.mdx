**Ruta:** `std::dbg`

## Sinopsis

```rust
macro_rules! dbg {
    () => { ... };
    ($val:expr $(,)?) => { ... };
    ($($val:expr),+ $(,)?) => { ... };
}
```

## Qué hace

`dbg!(expr)` escribe en la salida de errores `[archivo:línea:columna] expr = valor` (con formato `{:#?}`) y **devuelve** el valor, así que puedes envolver cualquier expresión sin cambiar lo que hace. Toma la propiedad del valor: usa `dbg!(&x)` si quieres seguir usando `x`. Quítalo antes de publicar tu código.

## Ejemplo

**Salida:**

```text
6 [1, 2]
```

**Salida de error** (*stderr*):

```text

[macros-dbg.rs:5:9] n * factorial(n - 1) = 6
[macros-dbg.rs:10:13] factorial(3) = 6
[macros-dbg.rs:12:5] &v = [
    1,
    2,
]
```

**Ruta:** `std::assert y familia`

## Sinopsis

```rust
macro_rules! assert {
    ($cond:expr $(,)?) => { ... };
    ($cond:expr, $($arg:tt)+) => { ... };
}

macro_rules! assert_eq {
    ($left:expr, $right:expr $(,)?) => { ... };
    ($left:expr, $right:expr, $($arg:tt)+) => { ... };
}

macro_rules! assert_ne {
    ($left:expr, $right:expr $(,)?) => { ... };
    ($left:expr, $right:expr, $($arg:tt)+) => { ... };
}
```

## Qué hace

`assert!(cond)` entra en pánico si la condición es falsa. `assert_eq!(a, b)` y `assert_ne!(a, b)` comparan dos valores y, si fallan, muestran los dos (necesitan `PartialEq` y `Debug`). Todas aceptan un mensaje con formato al final. Se comprueban **siempre**, también en *release*; `debug_assert!` y familia solo en *debug*.

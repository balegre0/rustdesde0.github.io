Todos estos métodos existen en Rust estable 1.99 (comprobado compilando cada uno). Además, un `Vec<T>` tiene todos los [métodos de las slices](/ref/std/slice/metodos/) (`sort`, `binary_search`, `chunks`, `windows`, `contains`, `first`, `iter`…), porque se convierte en `&[T]` automáticamente.

## Crear

| Forma | Qué hace |
|---|---|
| `Vec::new()`, `vec![]` | vacío, sin reservar |
| `Vec::with_capacity(n)` | vacío, con sitio para `n` |
| `vec![a, b, c]`, `vec![x; n]` | con elementos / `n` copias de `x` |
| `iter.collect::<Vec<_>>()` | desde cualquier iterador |

## Añadir

| Método | Qué hace | Coste |
|---|---|---|
| `push(x)` | al final | O(1) amortizado |
| `insert(i, x)` | en la posición `i` | O(n) |
| `extend(iter)`, `extend_from_slice(&s)` | varios al final | |
| `append(&mut otro)` | mueve todo `otro` al final (deja `otro` vacío) | |
| `resize(n, x)`, `resize_with(n, f)` | crecer o encoger hasta `n` | |

## Quitar

| Método | Qué hace | Coste |
|---|---|---|
| `pop()` | el último (`Option<T>`) | O(1) |
| `pop_if(p)` | el último, solo si cumple `p` (1.86) | O(1) |
| `remove(i)` | el de la posición `i`, conservando el orden | O(n) |
| `swap_remove(i)` | el de la posición `i`, poniendo el último en su sitio | O(1) |
| `truncate(n)`, `clear()` | dejar `n` / vaciar | |
| `drain(rango)` | quitar un rango y recorrer lo quitado | |
| `split_off(i)` | devuelve otro `Vec` con lo que había desde `i` | |

## Filtrar y deduplicar en el sitio

| Método | Qué hace |
|---|---|
| `retain(p)` | dejar solo los que cumplen `p` |
| `retain_mut(p)` | igual, pudiendo modificar cada uno (1.61) |
| `extract_if(rango, p)` | sacar los que cumplen `p` y devolverlos en un iterador (1.87) |
| `dedup()`, `dedup_by_key(f)`, `dedup_by(f)` | quitar repetidos **seguidos** |

## Capacidad y conversión

| Método | Qué hace |
|---|---|
| `len()`, `is_empty()`, `capacity()` | elementos / ¿vacío? / sitio reservado |
| `reserve(n)`, `reserve_exact(n)`, `shrink_to_fit()` | reservar / devolver sitio |
| `as_slice()`, `as_mut_slice()` | ver como `&[T]` / `&mut [T]` |
| `into_boxed_slice()` | `Box<[T]>`, sin capacidad sobrante |
| `leak()` | `&'static mut [T]`: renuncia a liberar la memoria |
| `get(i)`, `get_mut(i)` | acceso sin pánico (`Option`) |

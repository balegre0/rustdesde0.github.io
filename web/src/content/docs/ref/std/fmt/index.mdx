**Ruta:** `std::fmt`

## Para qué sirve

Este módulo está detrás de `println!`, `format!`, `write!` y compañía. Define la **mini-sintaxis** de las llaves (`{}`, `{:?}`, `{:>8.2}`…) y los traits que dicen cómo se muestra cada tipo: `Display` para `{}` (para personas) y `Debug` para `{:?}` (para programadores).

## Conceptos clave

- **Se comprueba al compilar**: si el texto pide `{}` y el tipo no implementa `Display`, no compila ([E0277](/errores/e0277/)). Si faltan o sobran argumentos, tampoco.
- **`to_string()` gratis**: todo tipo con `Display` tiene `.to_string()`.

**Ruta:** `std::fmt (la sintaxis de las llaves)`

## Qué hace

Cada `{...}` del texto es un **hueco** que se rellena con un argumento. Dentro puede haber, en este orden:

```text
{ argumento : relleno alineación signo # 0 ancho .precisión tipo }
```

| Parte | Ejemplos | Qué hace |
|---|---|---|
| argumento | `{}` `{0}` `{nombre}` | Cuál se imprime: el siguiente, por posición, o por nombre (también una variable del ámbito). |
| relleno + alineación | `{:<8}` `{:^8}` `{:>8}` `{:*^8}` | Izquierda, centro, derecha; con un carácter de relleno opcional. |
| signo | `{:+}` | Muestra siempre el signo. |
| `#` | `{:#x}` `{:#?}` | Forma alternativa: prefijo `0x`/`0b`/`0o`, o `Debug` en varias líneas. |
| `0` | `{:05}` | Rellena con ceros detrás del signo. |
| ancho | `{:8}` `{:ancho$}` `{:1$}` | Mínimo de caracteres. Puede venir de una variable (`nombre$`) o de un argumento (`n$`). |
| precisión | `{:.2}` `{:.*}` | Decimales de un número, o máximo de caracteres de un texto. `.*` toma la precisión del argumento anterior. |
| tipo | `?` `x` `X` `o` `b` `e` `E` `p` | `Debug`, hexadecimal, octal, binario, notación científica, dirección de un puntero. Sin tipo: `Display`. |

Para escribir una llave literal, duplícala: `{{` y `}}`.

**Salida:**

```text
uno y dos
dos y uno
Ana tiene 31 años
[     Ana]
[Ana     ]
[  Ana   ]
[**Ana***]
[00042]
3.14    3.142 +7
1010 12 ff FF 0xff 0b00000101
[(1, "a"), (2, "b")]
(
    1,
    "a",
)
[     1] [3.142]
{} y valor
1.2345e3
```

## Errores

Los errores de formato son **de compilación**: un nombre que no existe, un argumento que sobra o un tipo que no implementa el trait que pide el hueco.

**Ruta:** `std::fmt::Debug`

## Sinopsis

```rust
pub trait Debug {
    // Required method
    fn fmt(&self, f: &mut Formatter<'_>) -> Result<(), Error>;
}
```

## Qué hace

`Debug` muestra el valor «tal como es», pensando en quien programa: los textos salen entre comillas y los structs con sus campos. Casi siempre se **deriva** con `#[derive(Debug)]`. `{:#?}` lo muestra en varias líneas con sangría. Si quieres ocultar algo (una contraseña), impleméntalo a mano.

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`fmt`](#fmt) | Escribe la representación de depuración. | 1.0 |
| [`debug_struct`](#debug_struct) | Ayuda para implementarlo a mano con el mismo estilo que `derive`: `.field("x", &self.x).finish()`. | 1.2 |

### `fmt`

```rust
fn fmt(&self, f: &mut Formatter<'_>) -> Result<(), Error>
```

Escribe la representación de depuración.

### `debug_struct`

```rust
pub fn debug_struct<'b>(&'b mut self, name: &str) -> DebugStruct<'b, 'a>
```

Ayuda para implementarlo a mano con el mismo estilo que `derive`: `.field("x", &self.x).finish()`.

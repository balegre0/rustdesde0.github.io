**Ruta:** `std::fmt::Display`

## Sinopsis

```rust
pub trait Display {
    // Required method
    fn fmt(&self, f: &mut Formatter<'_>) -> Result<(), Error>;
}
```

## Qué hace

Implementa `Display` para decir cómo se ve tu tipo con `{}`. Solo tiene un método, `fmt`, que recibe un `Formatter` y escribe en él (casi siempre con `write!`). No se puede derivar: tienes que decidir tú el formato. El `Formatter` te da las opciones que pidió quien imprime (`precision()`, `width()`, `alternate()`…).

## Métodos principales

| Método | Qué hace | Desde |
|---|---|---|
| [`fmt`](#fmt) | Escribe la representación del valor en el `Formatter`. | 1.0 |
| [`precision`](#precision) | La precisión pedida (`{:.2}`), si la hay. | 1.5 |
| [`width`](#width) | El ancho pedido (`{:8}`), si lo hay. | 1.5 |

### `fmt`

```rust
fn fmt(&self, f: &mut Formatter<'_>) -> Result<(), Error>
```

Escribe la representación del valor en el `Formatter`. Devuelve `fmt::Result` (`Ok(())` o `Err(fmt::Error)`).

### `precision`

```rust
pub fn precision(&self) -> Option<usize>
```

La precisión pedida (`{:.2}`), si la hay.

### `width`

```rust
pub fn width(&self) -> Option<usize>
```

El ancho pedido (`{:8}`), si lo hay.

La **biblioteca estándar** (`std`) es el código que viene con Rust. Se apoya en dos capas más pequeñas: `core` (lo que funciona sin sistema operativo ni memoria dinámica) y `alloc` (lo que necesita memoria dinámica, como `Vec` o `String`). La insignia de cada ficha indica de qué capa viene.

Rust publica una versión estable **cada seis semanas**. Esta página resume qué trajo cada una al lenguaje, desde 1.0 hasta **1.99.1**, la versión que usa este curso.

## En una frase

Hay tres canales: **stable** (la versión que usas), **beta** (la siguiente, en pruebas) y **nightly** (cada noche, con características inestables tras `#![feature(…)]`). Lo que entra en estable no se rompe: el código que compila con una versión compila con las siguientes (salvo correcciones de errores de solidez).

## Fechas y numeración

- 1.0 salió el **15 de mayo de 2015**. Desde entonces: 1.1, 1.2… cada seis semanas. Las versiones de parche (como 1.99.1) corrigen errores graves.
- Cada versión indica en la tabla qué trajo al **lenguaje**; las novedades de la biblioteca estándar se documentan en cada ficha de `std`.
- Fuente: las notas de versión oficiales (`RELEASES.md`) incluidas con el propio compilador 1.99.1.

## Lo que viene

- **Rust 1.100** (beta en noviembre de 2026): en el compilador nightly, el tipo `!` ya aparece como estable para la versión 1.100.
- Siguen **inestables** (solo nightly), entre otros: bloques `gen` y `try`, especialización, `generic_const_exprs`, `type_alias_impl_trait`, *return type notation*, `deref_patterns`, `async_drop`, `default_field_values`, `explicit_tail_calls` (`become`), macros 2.0 (`macro`), `f16`/`f128`.
- El nuevo borrow checker **Polonius** (versión alfa) está activado en nightly, con el objetivo de estabilizarse.

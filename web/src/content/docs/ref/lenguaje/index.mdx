Esta es la **referencia del lenguaje**: fichas cortas y exactas para consultar, no para leer de corrido. Si estás aprendiendo desde cero, empieza por el [curso](/curso/) y vuelve aquí cuando quieras el detalle.

Todo lo que ves corresponde a **Rust 1.99.1, edición 2024**. Cada salida y cada error que aparecen se han obtenido compilando y ejecutando el ejemplo de verdad.

## Cómo leer una ficha

- **Sinopsis**: la forma exacta de escribirlo.
- **Qué hace**: el comportamiento, regla a regla.
- **Ejemplo**: un programa que puedes ejecutar en el navegador.
- **Errores**: el error real del compilador cuando se usa mal, y cómo arreglarlo.
- **Desde**: la versión de Rust (o la edición) en que apareció.
- **Ver también** y **Aprende esto en**: fichas relacionadas y la lección del curso.

[Todas las palabras clave](/ref/lenguaje/palabras-clave/): 39 estrictas (`as`, `fn`, `let`, `match`, `unsafe`…), 14 reservadas para el futuro (`gen`, `try`, `yield`…) y 5 débiles (`'static`, `macro_rules`, `raw`, `safe`, `union`).

`yield` es una palabra clave **reservada**: hoy no hace nada en Rust estable, pero está apartada para el futuro, así que no puedes usarla como nombre de variable, función, tipo, campo, módulo…

## Sinopsis

```text
yield          // sin significado en Rust estable 1.99
r#yield        // identificador crudo: «yield» usado como nombre normal
```

## Qué hace

Reservada desde Rust 1.0. Está pensada para las **corrutinas** y los generadores: `yield valor` entregaría un valor y pausaría la ejecución hasta que se pida el siguiente.

Existe un experimento **inestable** que la usa, la *feature* `coroutines` (y `gen_blocks`), disponible solo en el compilador *nightly*. En Rust estable 1.99 no se puede usar.

Reservar palabras de antemano permite añadir sintaxis nueva **sin romper** programas existentes: como nadie ha podido llamar `yield` a nada, el día que la palabra tenga significado ningún programa dejará de compilar.

Si necesitas ese nombre (por ejemplo, para hablar con otro sistema que usa un campo llamado así), escribe el **identificador crudo** `r#yield`: para el compilador es el nombre `yield` sin más.

## Errores

<NoCompila ej="ref-lenguaje/kw-yield" />

`error: expected identifier, found reserved keyword yield`, seguido de varios errores más (E0658 `yield syntax is experimental`, E0627): el compilador intenta entender `yield` como la expresión experimental de las corrutinas. El arreglo usa `r#yield`.

## Desde

Reservada desde Rust 1.0, en todas las ediciones.

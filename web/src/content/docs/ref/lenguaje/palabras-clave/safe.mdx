`safe` solo tiene significado **dentro de un bloque `unsafe extern`**: marca una función o un `static` externo que se puede usar **sin** bloque `unsafe`.

## Sinopsis

```text
unsafe extern "C" {
    pub safe fn f(x: i32) -> i32;      // se llama sin unsafe
    pub unsafe fn g(p: *const u8);      // se llama dentro de unsafe
    fn h();                             // sin marca: igual que unsafe
    pub safe static N: i32;
}
```

## Qué hace

Al escribir `unsafe extern`, prometes que las firmas declaradas son correctas. Con `safe` prometes **además** que llamar a esa función es seguro **con cualquier argumento válido de su tipo**. Por ejemplo, una función que calcula el valor absoluto de un `i32` puede ser `safe`; una que lee de un puntero, no.

Si esa promesa es falsa, el código seguro que la llama podría provocar comportamiento indefinido sin escribir `unsafe`: la culpa es de la declaración.

Fuera de un bloque extern, `safe` es un identificador normal.

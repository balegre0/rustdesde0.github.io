`false` es uno de los dos valores del tipo `bool`; el otro es [`true`](/ref/lenguaje/palabras-clave/true/).

## Sinopsis

```text
false : bool
```

## Qué hace

- `bool` ocupa **1 byte**. En memoria, `false` es el byte `0` y `true` el byte `1`. Cualquier otro byte en un `bool` es un valor inválido: crearlo con `unsafe` es [comportamiento indefinido](/ref/ub/).
- `false as u8` vale `0`.
- Las condiciones de `if` y `while` exigen un `bool`: un número no sirve como condición.
- `&&` y `||` hacen **cortocircuito**: en `false && x`, `x` ni se evalúa.
- Como los valores 2…255 están prohibidos, el compilador los aprovecha como nichos: `Option<bool>` ocupa 1 byte.

## Errores

<NoCompila ej="ref-lenguaje/kw-false-error" />

`error[E0308]: mismatched types` con `expected bool, found integer`. Escribe la comparación explícita: `if n != 0`.

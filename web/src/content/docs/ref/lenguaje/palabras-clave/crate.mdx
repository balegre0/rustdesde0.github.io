Un **crate** es la unidad que compila `rustc` de una vez: un programa o una biblioteca. La palabra clave `crate` nombra **el crate actual**.

## Sinopsis

```text
crate::ruta::al::elemento      // ruta absoluta desde la raíz de este crate
pub(crate) elemento            // visible en todo este crate, no fuera
extern crate nombre;           // enlazar con otro crate (casi nunca hace falta)
extern crate nombre as alias;
$crate                         // dentro de macro_rules: el crate que define la macro
```

## Qué hace

### Uso 1 · Rutas desde la raíz

`crate::a::b` empieza a buscar en la raíz del crate (`main.rs` o `lib.rs`), sin importar desde qué módulo lo escribas. Es la forma más clara de nombrar algo lejano.

### Uso 2 · Visibilidad `pub(crate)`

Hace un elemento público **solo dentro del crate**. Es la visibilidad habitual para lo que comparten tus módulos pero no quieres exponer a quien use tu biblioteca.

### Uso 3 · `extern crate`

Declara que se usa otro crate. Desde la edición 2018, Cargo pasa las dependencias directamente y esta línea sobra casi siempre; sigue teniendo usos raros, como `extern crate alloc;` en programas `#![no_std]`.

### Uso 4 · `$crate`

Solo dentro de `macro_rules!`: se sustituye por la ruta al crate que **define** la macro, para que funcione aunque la use otro crate.

`crate` no puede usarse como nombre, ni siquiera como identificador crudo `r#crate`.

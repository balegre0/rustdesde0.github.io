Una **palabra clave** (*keyword*) es una palabra que el lenguaje usa para sí mismo. Rust las divide en tres grupos según lo que te dejan hacer con ellas.

## Las tres categorías

- **Estrictas**: tienen un significado fijo y **no** pueden usarse como nombre de nada (variables, funciones, tipos, campos, módulos, etiquetas, tiempos de vida, macros, crates…).
- **Reservadas**: hoy no significan nada en Rust estable, pero están apartadas para el futuro. Tienen las mismas restricciones que las estrictas.
- **Débiles**: solo son especiales en un contexto concreto. Fuera de él son identificadores normales: `let union = 1;` es válido.

## Identificadores crudos `r#`

Si necesitas usar una palabra clave como nombre (por ejemplo, porque otro sistema tiene un campo llamado `type`), escribe un **identificador crudo** (*raw identifier*): `r#type`. Para el compilador es el nombre `type`, sin más. Funciona con todas las palabras clave **excepto** `crate`, `self`, `super` y `Self`. Existe desde Rust 1.30.

Las palabras clave dependen de la **edición**: `async`, `await` y `dyn` son estrictas desde 2018; `try` está reservada desde 2018 y `gen` desde 2024. Un crate de la edición 2015 puede seguir llamando `async` a una función, y otro crate de la 2024 puede usarla escribiendo `r#async`. Ver [Ediciones](/ref/ediciones/).

`super` en una ruta significa **el módulo padre** del actual.

## Sinopsis

```text
super::elemento
super::super::elemento      // el abuelo
pub(super) elemento         // visible en el módulo padre
use super::*;               // muy común en los módulos de pruebas
```

## Qué hace

- Sube un nivel en el árbol de módulos. Se puede encadenar al principio de la ruta.
- Es una ruta **relativa**: si mueves el módulo entero, sigue funcionando.
- Uso típico: en `mod tests { use super::*; }`, para probar las funciones privadas del módulo que contiene las pruebas.
- `super` no puede usarse como nombre, ni con `r#super`.

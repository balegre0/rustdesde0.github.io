`unsized` es una palabra clave **reservada**: hoy no hace nada en Rust estable, pero está apartada para el futuro, así que no puedes usarla como nombre de variable, función, tipo, campo, módulo…

## Sinopsis

```text
unsized          // sin significado en Rust estable 1.99
r#unsized        // identificador crudo: «unsized» usado como nombre normal
```

## Qué hace

Reservada desde Rust 1.0. No tiene uso en el lenguaje actual; los tipos sin tamaño conocido se expresan con el límite `?Sized`.

Reservar palabras de antemano permite añadir sintaxis nueva **sin romper** programas existentes: como nadie ha podido llamar `unsized` a nada, el día que la palabra tenga significado ningún programa dejará de compilar.

Si necesitas ese nombre (por ejemplo, para hablar con otro sistema que usa un campo llamado así), escribe el **identificador crudo** `r#unsized`: para el compilador es el nombre `unsized` sin más.

## Errores

<NoCompila ej="ref-lenguaje/kw-unsized" />

`error: expected identifier, found reserved keyword unsized`, con la ayuda `escape unsized to use it as an identifier`. El arreglo usa `r#unsized`.

## Desde

Reservada desde Rust 1.0, en todas las ediciones.

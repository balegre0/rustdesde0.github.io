`typeof` es una palabra clave **reservada**: hoy no hace nada en Rust estable, pero está apartada para el futuro, así que no puedes usarla como nombre de variable, función, tipo, campo, módulo…

## Sinopsis

```text
typeof          // sin significado en Rust estable 1.99
r#typeof        // identificador crudo: «typeof» usado como nombre normal
```

## Qué hace

Reservada desde Rust 1.0. No tiene uso en el lenguaje actual.

Reservar palabras de antemano permite añadir sintaxis nueva **sin romper** programas existentes: como nadie ha podido llamar `typeof` a nada, el día que la palabra tenga significado ningún programa dejará de compilar.

Si necesitas ese nombre (por ejemplo, para hablar con otro sistema que usa un campo llamado así), escribe el **identificador crudo** `r#typeof`: para el compilador es el nombre `typeof` sin más.

## Errores

<NoCompila ej="ref-lenguaje/kw-typeof" />

`error: expected identifier, found reserved keyword typeof`, con la ayuda `escape typeof to use it as an identifier`. El arreglo usa `r#typeof`.

## Desde

Reservada desde Rust 1.0, en todas las ediciones.

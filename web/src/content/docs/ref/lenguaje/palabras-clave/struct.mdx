Un `struct` (estructura) junta **varios valores** en un solo tipo nuevo. Cada valor es un **campo**.

## Sinopsis

```text
struct Nombre<genéricos> where … { campo: Tipo, pub otro: Tipo }   // campos con nombre
struct Nombre(Tipo1, pub Tipo2);                                   // struct tupla
struct Nombre;                                                     // struct unidad
Nombre { campo: valor, otro, ..base }                              // expresión
```

## Qué hace

- **Campos con nombre**: se accede con `valor.campo`. Al construir, `Usuario { edad }` es un atajo de `edad: edad`.
- **Struct tupla**: campos sin nombre, accedidos como `.0`, `.1`. Muy usado para *newtypes* (`struct Metros(f64)`), que crean un tipo **distinto** sin coste.
- **Struct unidad**: sin campos; ocupa 0 bytes. Útil como marcador o para implementar traits.
- **Actualización** `..base`: rellena los campos que faltan desde otro valor. Ojo: **mueve** los campos que no son `Copy`.
- Hay que dar **todos** los campos al construir (salvo con `..base`).
- La privacidad es **por campo**. La mutabilidad no: depende de la variable (`let mut u`).
- El compilador puede **reordenar** los campos en memoria para ahorrar relleno; con `#[repr(C)]` se respeta el orden. Ver [Layout de tipos](/ref/lenguaje/layout-de-tipos/).

`become` es una palabra clave **reservada**: hoy no hace nada en Rust estable, pero está apartada para el futuro, así que no puedes usarla como nombre de variable, función, tipo, campo, módulo…

## Sinopsis

```text
become          // sin significado en Rust estable 1.99
r#become        // identificador crudo: «become» usado como nombre normal
```

## Qué hace

Reservada desde Rust 1.0. Está pensada para las **llamadas de cola explícitas** (*tail calls*): `become f(x)` sustituiría el marco de la función actual por el de `f`, sin hacer crecer la pila.

Existe un experimento **inestable** que la usa, la *feature* `explicit_tail_calls`, disponible solo en el compilador *nightly*. En Rust estable 1.99 no se puede usar.

Reservar palabras de antemano permite añadir sintaxis nueva **sin romper** programas existentes: como nadie ha podido llamar `become` a nada, el día que la palabra tenga significado ningún programa dejará de compilar.

Si necesitas ese nombre (por ejemplo, para hablar con otro sistema que usa un campo llamado así), escribe el **identificador crudo** `r#become`: para el compilador es el nombre `become` sin más.

## Errores

<NoCompila ej="ref-lenguaje/kw-become" />

`error: expected identifier, found reserved keyword become`, con la ayuda `escape become to use it as an identifier`. El arreglo usa `r#become`.

## Desde

Reservada desde Rust 1.0, en todas las ediciones.

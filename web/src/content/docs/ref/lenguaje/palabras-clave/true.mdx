`true` es uno de los dos valores del tipo `bool`; el otro es [`false`](/ref/lenguaje/palabras-clave/false/).

## Sinopsis

```text
true : bool
```

## Qué hace

- En memoria es el byte `1`; `true as i32` vale `1`.
- `!true` es `false`.
- `true || x` no evalúa `x` (cortocircuito).
- `bool` está ordenado: `false < true`.
- `cond.then_some(v)` da `Some(v)` si `cond` es `true`, y `None` si es `false`; `cond.then(|| …)` hace lo mismo calculando el valor solo cuando hace falta.
- Desde Rust 1.88 también puedes escribir `cfg(true)` y `cfg(false)` en compilación condicional.

## Errores

Los mismos que [`false`](/ref/lenguaje/palabras-clave/false/): una condición tiene que ser `bool`, no un número.

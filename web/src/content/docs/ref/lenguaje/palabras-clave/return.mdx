`return` termina la función **en ese momento** y entrega un valor a quien la llamó.

## Sinopsis

```text
return expresión
return            // equivale a return ()
```

## Qué hace

- Sale de la función, closure o bloque `async` **más interior**. Dentro de una closure, `return` sale de la closure, no de la función que la contiene.
- Antes de salir, se destruyen las variables locales vivas (en orden inverso de declaración).
- El valor debe tener el tipo de retorno declarado.
- La expresión `return …` tiene tipo `!`: por eso cabe en cualquier rama de un `if` o `match`.
- Al final del cuerpo no hace falta: la última expresión sin `;` ya es el valor devuelto. `return` se reserva para **salir antes**.
- El operador `?` es un `return` abreviado para errores: si el valor es `Err` (o `None`), lo devuelve.

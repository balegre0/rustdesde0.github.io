`let` crea **variables**: le da nombre a un valor para poder usarlo después.

## Sinopsis

```text
let patrón: Tipo = expresión;                 // tipo e inicializador opcionales
let patrón = expresión else { …diverge… };    // let-else
if let patrón = expresión { … }
while let patrón = expresión { … }
```

## Qué hace

- Las variables son **inmutables** por defecto. `let mut x` permite cambiarlas.
- El tipo se deduce casi siempre; `let x: u8 = 5;` lo fija.
- La parte izquierda es un **patrón**: `let (a, b) = par;` desestructura. En un `let` simple, el patrón debe ser **irrefutable** (no puede fallar); para patrones que pueden fallar usa `let … else`, `if let` o `match`.
- **Sombreado** (*shadowing*): un nuevo `let` con el mismo nombre crea **otra** variable; la anterior queda tapada. Puede tener otro tipo.
- **Inicialización diferida**: `let x;` sin valor está permitido; el compilador comprueba que se asigna una vez antes de cada lectura.
- La variable vive hasta el final de su bloque; entonces su valor se destruye (en orden inverso de declaración).

`while` repite su bloque **mientras** una condición sea verdadera (o mientras un patrón encaje, con `while let`).

## Sinopsis

```text
'etiqueta: while condición { … }
while let patrón = expresión { … }
while let P = e && condición { … }      // cadena let (edición 2024)
```

## Qué hace

- Comprueba la condición **antes** de cada vuelta; si de entrada es falsa, el cuerpo no se ejecuta nunca.
- `while let` vuelve a evaluar la expresión en cada vuelta y sigue mientras encaje el patrón. Es el modo típico de vaciar una pila: `while let Some(x) = pila.pop()`.
- Un `while` siempre vale `()`; su `break` no puede llevar valor.
- Admite `break`, `continue` y etiquetas.

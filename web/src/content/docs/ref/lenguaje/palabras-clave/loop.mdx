`loop` repite su bloque **para siempre**, hasta que un `break` (o un `return`) lo detiene.

## Sinopsis

```text
'etiqueta: loop { cuerpo }       // la etiqueta es opcional
let v = loop { … break valor; };
```

## Qué hace

- `loop` es una **expresión**. Su valor es el que lleva el `break` que lo termina. Todos los `break` de un mismo `loop` deben dar valores del mismo tipo.
- Un `loop` sin ningún `break` tiene tipo `!` (*never*): el compilador sabe que el código detrás nunca se ejecuta. Por eso `fn servidor() -> ! { loop { … } }` es válido.
- El compilador entiende que un `loop` siempre entra en el cuerpo. Gracias a eso, una variable asignada dentro antes del `break` cuenta como inicializada después.
- Úsalo cuando la condición de salida está **en medio** del cuerpo o cuando necesitas reintentar algo hasta que funcione.

`mod` crea un **módulo**: una caja con nombre que agrupa funciones, tipos y otros módulos, y que decide qué se ve desde fuera.

## Sinopsis

```text
mod nombre { elementos }       // módulo en línea
mod nombre;                    // módulo en otro archivo
#[path = "otro.rs"] mod nombre;
```

## Qué hace

- Un módulo es un **espacio de nombres**: `geometria::formas::area` no choca con otra `area` de otro módulo.
- Todo lo de dentro es **privado** por defecto: solo lo ven el propio módulo y sus descendientes. `pub` lo abre.
- `mod nombre;` le dice al compilador que cargue el contenido de un archivo. Si lo escribes en `src/main.rs` (o `src/lib.rs`), busca `src/nombre.rs` o `src/nombre/mod.rs`. Si lo escribes en `src/a.rs`, busca `src/a/nombre.rs` (o `src/a/nombre/mod.rs`).
- Los archivos **no** se convierten en módulos por existir: solo si alguien los declara con `mod`.
- El conjunto de módulos forma un **árbol** cuya raíz es el crate. Las rutas `crate::`, `self::` y `super::` se mueven por ese árbol.

`#![feature(…)]` activa una característica que todavía no es estable.

## Sinopsis

```rust
#![feature(never_type, try_blocks)]
```

## Qué hace

Las novedades de Rust se implementan primero **detrás de una feature** (la «puerta» de la característica). Solo el compilador **nightly** acepta `#![feature]`; en stable y beta es el error E0554. Cada feature tiene una **incidencia de seguimiento** en el repositorio de Rust, enlazada desde el *Unstable Book* (`rustup doc --unstable-book`), donde se discute su estado.

Para probarlas:

```powershell
rustup toolchain install nightly
cargo +nightly run
```

Úsalas para **experimentar**, no en código que tenga que compilar dentro de un año: pueden cambiar o desaparecer.

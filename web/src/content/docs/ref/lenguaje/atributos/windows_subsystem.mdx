Un `.exe` de Windows declara a qué **subsistema** pertenece. El de consola abre una ventana negra al arrancar; el de ventanas, no.

## Sinopsis

```text
#![windows_subsystem = "console"]   // por defecto
#![windows_subsystem = "windows"]   // sin consola
```

## Qué hace

Con `"windows"`, al hacer doble clic en el programa no aparece la consola. Es lo que quieres en un programa con interfaz gráfica. A cambio, `println!` no se ve. Se ignora fuera de Windows.

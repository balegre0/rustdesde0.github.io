Cada módulo recibe automáticamente el **preludio** (`std::prelude::rust_2024`): `Vec`, `String`, `Option`, `Some`, `Ok`, `Box`, `println!`… `#[no_implicit_prelude]` lo quita.

## Sinopsis

```text
#[no_implicit_prelude]
mod m { … }
#![no_implicit_prelude]   // para todo el crate
```

## Qué hace

Dentro del módulo (y de sus hijos) no hay preludio, ni el de la biblioteca estándar ni las macros de `#[macro_use]`. Hay que escribir rutas absolutas: `::std::vec::Vec`, `::std::println!`. Lo usan, sobre todo, las **macros** que generan código y tienen que funcionar aunque el usuario haya definido su propio `Option` o `Vec`: por eso dentro de las macros se escribe `::core::option::Option::Some`.

`#[deprecated]` avisa a quien use un elemento de que dejará de existir o de que hay una alternativa mejor.

## Sinopsis

```text
#[deprecated]
#[deprecated = "nota"]
#[deprecated(since = "2.0.0", note = "usa `nueva` en su lugar")]
```

Se aplica a casi cualquier elemento: funciones, tipos, campos, variantes, traits, módulos, constantes.

## Qué hace

Cada uso del elemento genera el aviso `deprecated` (nivel *warn*), con la nota. No cambia nada del programa: el elemento sigue funcionando. Es la forma correcta de retirar algo de una biblioteca: márcalo en una versión menor y quítalo en la siguiente mayor.

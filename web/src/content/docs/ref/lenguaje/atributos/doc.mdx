`#[doc]` contiene la documentación de un elemento y ajusta cómo la muestra rustdoc.

## Sinopsis

```text
#[doc = "texto en Markdown"]      // lo mismo que /// texto
#![doc = "…"]                     // lo mismo que //! texto
#[doc = include_str!("../README.md")]
#[doc(hidden)]                    // no aparece en la documentación
#[doc(alias = "add")]             // el buscador lo encuentra por otro nombre
#[doc(inline)] / #[doc(no_inline)] // en pub use: mostrar el elemento ahí o solo un enlace
#![doc(html_logo_url = "…")]      // opciones del crate
#![doc(test(attr(deny(warnings))))] // atributos para los doctests
```

## Qué hace

`///` y `//!` se convierten en `#[doc = "…"]` antes de compilar. El texto es Markdown y admite enlaces entre elementos (``[`Vec`]``). `doc(hidden)` se usa en elementos que tienen que ser públicos por motivos técnicos (los usa una macro, por ejemplo) pero no forman parte de la interfaz prometida.
